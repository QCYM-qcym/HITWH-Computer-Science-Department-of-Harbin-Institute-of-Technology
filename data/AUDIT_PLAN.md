# W1 数据审计入口

日期：2026-10-21。范围：提供方 UGR16v3 的 MAT/CSV 核验与规范 CSV 适配。状态：真实 Data Gate 未通过；结果见 [审计记录](AUDIT_REPORT.md)。

1. 固定提供方提交与载荷 SHA256，分开登记仓库 GPL-3.0 与论文数据使用声明；不公开再分发载荷。
2. 逐列、逐值核对 X/Y、CSV/MAT、Row 与 obs_l/obs_lt；核对134维和八标签顺序。
3. 以原始时钟检查乱序、重复、缺口、非法计数及标签分布。没有时区证据时只描述本地时钟，不标为 UTC。
4. 先确定时间来源及提供方测试范围，再登记训练、参数验证、独立校准、测试四个半开区间。保留完整轴，不补零或拼接正常行。
5. 用原始轴检查当前及此前 H 分钟均为八标签零的候选资格；报告正常/攻击覆盖及排除计数。测试历史不按标签清洗。
6. 真实时间、来源使用条件、四段边界与正常样本条件全部满足后，才考虑解除真实执行限制；字段/协议变化交 W0 和用户决定。

规范 CSV 的列序为 `timestamp`、DatasetSchema 内134个字段、可选的八个标签。该格式是显式交换格式；不把 `Row` 自动解释为 UTC。冲突分钟保留无效占位，冲突标签不造零；缺分钟不创建记录。该结构审计的 passed 不等于完整 Data Gate。
