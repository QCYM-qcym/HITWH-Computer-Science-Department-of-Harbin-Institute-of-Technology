# 实验记录模板

用途：获准运行时复制为单次记录。修订2026-10-11；状态模板；范围P0检测/对比/消融；依据[路线图](../docs/project/ROADMAP.md)及时间/泄漏边界。本文件无实验编号、结果或运行证据。

| 字段 | 要求 |
|---|---|
| 编号/任务/RQ | 唯一实验编号，研究假设、任务/RQ/验收对应 |
| 日期/状态 | 实际起止；NOT_RUN或FAILED；最小运行/完整实验分开 |
| 代码/环境 | 已存在执行提交号、未提交差异；系统/Python/依赖锁/硬件 |
| 数据 | 来源/许可/版本、相对输入索引、校验算法/值、Schema、审计报告 |
| 特征/标签 | 字段、转换、拟合边界；标签筛选/评价用途 |
| 时间划分 | 训练/模型验证/阈值校准/测试区段，测试不调参 |
| 方法/配置 | 模型、窗口、超参、阈值校准、种子、配置/校验摘要 |
| 因果边界 | 先评分再更新、预热、缺测、断点和污染策略 |
| 产物 | 原始分数、模型、日志相对索引/校验值，大文件保管/获取说明 |
| 指标/资源 | 实测误报/召回、口径/不确定性、时间/内存/显存 |
| 失败/局限 | 原因、重试新编号、负结果、缺分母/标签、适配差异 |
| 结论/复核 | 可支持/不可支持结论；复算、重载、独立复现命令和结果 |

索引保留所有尝试，不只选最优。原始分数和统一协议可复核后才写结论；测试不参与选窗/参数/阈值。
