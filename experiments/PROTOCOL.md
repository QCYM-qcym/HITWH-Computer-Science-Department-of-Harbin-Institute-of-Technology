# W1 实验协议与执行边界

日期：2026-10-21。版本：W1开发协议v1。依据：[公共契约](../docs/design/contracts-v1.md)、[报告V0.40](../docs/reports/开题报告-V0.40-公开文本.md)、[真实审计](../data/AUDIT_REPORT.md)。状态：程序合成验证；正式研究 **NOT_RUN**。

输入固定134维非负计数；训练正常窗口拟合 log1p 后的均值/总体标准差，零方差 scale=1。所有方法按同一 H 的完整原始轴选取当前及历史均正常的训练/校准分钟，四段分别预热；每段开头、时间缺口与无效输入重置历史。当前分钟不进入自己的参考。标准化后计算连续历史中位数/MAD，残差保持符号，不裁剪或二次缩放；当前/历史通道合为268维。

IF 分数取负 score_samples，越大越异常。当前 AE 为134维均方重构误差；历史 AE 为268维均方误差，两通道等权。AE 验证只使用参数验证段的正常候选，按验证损失选择保存轮次；不访问测试标签或进行测试调参。每种模型分别在独立校准段的共同正常分钟上取 linear 99%分位数，严格大于阈值报警；score 子命令只加载已保存阈值。

测试历史不读取标签。评价按时间对齐八类标签，未知标签不记正常；四类主要攻击优先于背景标签。混淆计数使用共同有效分钟，零分母输出 null 和原因，完整预测保持逐点身份。未报警攻击片段由原始标签轴确定，不把一次命中扩成整段命中。背景仅单列，缺失、预热与被排除攻击保留覆盖分母。

同一 H 的三个合成运行采用相同有效分钟。`intersect_timestamp_masks` 提供不同窗口/轴的交集计算，但尚未建立跨窗口共同训练、校准、测试的研究编排器；不能直接将各自不同 H 的单次运行视作公平研究比较。正式窗口15/30、seed 42/2024/3407、同宽与近参数量对照、分攻击召回、正常高负载统计及持续攻击分析均待 Data Gate 解除后实施。五类协议计数未核实前 flow_count=null、高负载指标不可用。

本轮真实模型、epsilon真实数值稳定性、GPU、进程峰值内存及正式效率实验均 NOT_RUN。summary.peak_memory_bytes=0 是未测量占位，runtime.json 明确 memory_measurement=NOT_RUN；不得据此声称零内存消耗。合成耗时不能推断真实数据性能。
