# 时间感知网络流量异常检测文献综述

研究问题

网络流量会随业务时段变化，正常负载升高与攻击活动可能同时表现为计数增加。相关研究需要解释观测对象、历史信息的使用方式，以及检测效果如何验证。本综述围绕分钟特征、自编码器和时间信息，整理与本课题直接相关的方法。

流量表示与检测模型

Camacho与Rodríguez-Gómez研究了UGR16的特征表示和数据质量，指出训练污染与流方向处理会影响异常检测评价[1]。作者提供的分钟特征将满足地址类别、端口、协议及规模条件的流记录分别计数。这种表示适合分析连续分钟的变化，但聚合后不能直接恢复攻击IP或单条连接。因而，特征含义与时间标签对应关系应先于模型训练核验。

Mirsky提出的Kitsune利用自编码器集成学习正常网络行为，以重构误差发现异常[2]。其意义在于利用多个特征之间的关系判断偏离，而不只检查单个计数是否增大。周阳所在研究团队进一步按属性和方差分组特征，通过多个自编码器分别学习，再利用验证数据选择和融合模型[3]。这些方法为本课题采用重构模型、检查端口与TCP标志组的作用提供了依据，但其输入粒度与融合机制不能直接视为本课题单AE的实验结果。

历史信息的利用

Audibert提出的USAD将连续观测组织为窗口，利用共享编码器和双解码器进行对抗式训练[4]。窗口使模型接收到连续历史信息，代价是输入维度及训练开销增加。本课题拟复现该结构，并分别保存全窗口评分与末端分钟评分，避免将窗口命中直接当作其中每一分钟都被检出。

杨文川参与的研究采用Rényi熵描述流量分布，在固定时间窗口内用改进EWMA生成动态阈值[5]。这条路线把历史用于判定范围的调整，USAD则将历史直接放入模型输入。本课题拟在保持测试阈值固定的条件下，将当前值相对历史中位数和MAD的残差作为附加输入，以便检查历史表示本身的作用。分钟计数不能完整恢复熵方法所需的原始分布，故不直接照搬其特征计算。

评价要求与本课题的切入点

Kim的研究表明，逐点调整可能使时间序列异常检测结果偏高，一次报警不能自动算作整段异常都被检出[6]。据此，本课题拟按时间顺序划分训练、验证、校准与测试，预处理仅在训练数据拟合，阈值只由校准数据确定，最终按原始分钟标签评价。

拟比较当前AE、USAD适配与历史增强AE，并增加参数量相近的当前AE，区分历史信息与模型容量的作用。随后删去端口或TCP标志组重新训练，比较不同历史窗口，并检查持续攻击进入窗口后的分数变化。重点报告正常高负载误报和分攻击召回；若误报减少但漏报增加，应说明这种权衡。现有文献支持这些技术作为研究基础，组合方案是否有效仍需实验验证。
