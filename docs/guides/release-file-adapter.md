# 发布记录的有界文件适配

日期：2026-11-06。用途：候选数据适配工程。文件读取、磁盘聚合、独立复审、安装及分级人工容量验收已完成。所有实际输入均为新生成的人工文件，真实载荷、真实特征矩阵和模型运行仍为 `NOT_RUN`。

本模块接续[发布格式计算](release-format-adapter.md)，解决完整记录人口必须留在内存的问题。原bytes入口及完整批次参考算法保持原上限；新的文件入口逐条读取，使用本次调用独占的临时SQLite库保存判重与计算所需的小投影。接口不发现目录、不下载、不提供模型执行或分钟包写出功能。

## 输入身份和完成条件

调用方显式提供1—5个普通本地文件的路径、预期大小和SHA-256。所有源必须完整读取；同一次读取的实际字节同时用于SHA和CSV解码。单个源只打开一次内容流，不在结束时另读一遍计算摘要。文件状态检查帮助发现普通变化，不能证明目录快照、采集完整性或作者身份。

文件读取器只有在全部源到达EOF、大小和SHA匹配、所有源句柄关闭后才提供不可变读取凭据。提前正常退出会报未完成；中途校验失败不会留下可作为成功证明的部分凭据。调用方提供的摘要与内容相符，只说明本次一致性，结果仍为 `NOT_AUTHENTICATED`。

| 护栏 | 上限与含义 |
|---|---|
| 源文件 | 1—5个，实际读取总量最多2GiB，调用方可收紧 |
| 记录 | 最多250万条；超额整次失败，不截断后继续 |
| CSV | 固定91列，每字段4096字符；单逻辑记录含物理换行最多1MiB字符 |
| 实际读取 | 最底层无缓冲，每次请求最多64KiB；越界检测最多额外1字节 |
| 词汇与整数 | 沿原解析器的有界词汇和4096位整数规则，不更改进程全局设置 |
| 时间 | 整次聚合共享最多1800秒合作式截止检查；清理时间另计，不是操作系统硬超时 |
| 登记轴 | 最多7段、10000分钟，沿原时间顺序与跨段规则 |
| 主数据库 | 最多2GiB逻辑页空间；不等于整个文件系统或进程内存配额 |

这些是允许请求的上限，不能保证任意满足行数上限的输入都能完成。例如合法的极长整数仍可能先耗尽数据库预算。具体容量只能由实际负载验收记录说明。

## 全量判重和精确统计

临时库保存完整91字段的词法指纹、重复次数、分钟位置、整数duration、四个计数及固定资格诊断，不保存IP、Flow ID或完整源行。全部输入包括区间外和无法落桶记录都参与判重；晚到的重复记录仍使其早期副本一并排除。全部读取校验成功后，才计算最终分钟。

计数以十进制TEXT存入库，读取后由Python整数汇总，不经SQLite的64位整数或浮点聚合。duration保持微秒整数。空库预建固定覆盖索引，最终按分钟和duration顺序扫描，只保留median/P95需要的样本位置；不在Python中保存全部duration，不用近似分位。

数值资格、标签含义、跨段、无法落桶全域污染、空桶未知和三政策映射与完整批次参考一致。污染分钟内其他合格行仍计入eligible，但该分钟输出13个空值。分位扫描的计数核对只针对最终有效分钟，不能为了核对通过清零污染分钟的eligible。最后进行有理插值、转秒与有限浮点物化；失败整次停止。

## 临时空间与失败处理

scratch必须是本次新建的普通目录，仅包含固定所有权标记和主数据库。已有目录拒绝，失败库不恢复、不续算。数据库配置、实际页上限和固定查询计划均需回读检查；禁止后建索引、临时排序、额外源副本及隐式恢复流程。

正常或异常退出都先关闭源及数据库句柄，再复核目录、文件身份、所有权标记和成员集合，只删除本次拥有的两个文件及空目录。发现未知成员或所有权变化时，不自动删除或覆盖。关闭或清理失败不得返回正常成功；进程被强制结束可能留下INCOMPLETE目录，后续仍拒绝复用。删除不表示安全擦除。

主库页上限、抽样观察的目录尺寸、进程峰值工作集分别记录。人工大规模验收另设父进程超时和内存观测停止目标；这不构成通用进程树管理、连续磁盘监测或操作系统内存硬隔离。

## 验收与研究边界

先以小型人工文件逐字段对照原参考算法，覆盖乱序、最后一行重复、区间外重复、未知标签、Protocol0、污染桶及晚到不可落桶记录、大整数、精确分位和失败清理。安装包验收必须确认实际导入位置，不能仅以源码测试代替。

容量验收按一万、十万、2,099,976条人工记录逐级推进；前一级未通过不启动后一级。独立生成器使用七个人工2020日期段、2439分钟和五个新文件，与真实审计日期及供给计数分开。约六成记录集中在单个有效分钟，另有最后文件才出现的跨文件重复；期望值来自独立整数公式及固定直方图。

人工容量通过只说明该负载的实现与资源观测。它不认证真实采集覆盖、生成版本、实际导出延迟或最终标签政策，也不授权真实IF/AE运行。Data Gate保持BLOCKED，正式比较及论文效果结论仍未执行。


## 本次实际结果

实现为[_release_file_reader.py](../../src/core/traffic_anomaly/_release_file_reader.py)和[_release_disk.py](../../src/core/traffic_anomaly/_release_disk.py)。相关四模块测试387项通过、5项主机文件操作限制跳过，其中本批新增160项通过；独立复审及额外8个小型边界场景通过。安装后的53个核心源码文件一致，仓库外7个手工场景通过。测试见[读取器](../../tests/core/test_release_file_reader.py)与[磁盘聚合](../../tests/core/test_release_disk.py)。

一万、十万和2,099,976条人工记录全部通过逐字段独立核对。完整负载五源共1,370,754,146字节，源生成约25.18秒，聚合约161.85秒，独立期望值核对约1.88秒。主库254,590,976字节，Windows原生进程峰值工作集86,716,416字节；该峰值包含解释器、依赖和独立oracle，不是通用性能承诺或RSS硬配额。

完整负载的五源各打开一次，2,099,974个不同词法指纹中有两组跨文件重复，四个副本均排除；合格记录2,099,972条，2439分钟中2437个有效。集中桶包含1,259,984条记录，其max/median/P95秒值为1.259984/0.6299925/1.19698485，符合独立闭式答案。源摘要及所有24个结果字段核对一致，scratch已清理；这些均为人工计数，与真实供应审计分开。

真实进程硬终止验收在500条人工记录写入后进行，核对实际计算PID后强制结束并回收。残留INCOMPLETE目录保留作私有证据，再次调用在打开源内容前拒绝复用。首次父进程内存监控误读Windows虚拟环境启动器；发现后保留原记录，修正为实际进程并复核环境和PID，同一万人口重跑通过，再扩大规模。详细失败、修正、观测范围及数值见[本批验证记录](../research/2026-11-06-release-file-verification.json)。
