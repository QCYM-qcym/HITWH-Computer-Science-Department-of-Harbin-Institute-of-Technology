# IF 学习树导出到 P1 的人工数值兼容观察

日期：2026-11-12。状态：仅接受固定十例的数值兼容观察。完整冻结控制器契约仍为 `INCOMPLETE`（C0/I1/M0），父进程原始 stdout/stderr 未单独捕获。范围与完整人工分数见[验证记录](../research/2026-11-12-iforest-export-compatibility-verification.json)。本轮没有生产代码变更。

本轮在锁定环境中分别新拟合十个固定人工 IsolationForest，将各自保留的原模型树导出到未改动的 [P1 数值状态](iforest-numeric-state.md)，再由独立子进程解码、重编码并评分。参考来自同一个原模型唯一一次 `-score_samples` 返回；逐项比较全部 binary64 `float.hex()`，不使用容差或重拟合。任意人工坐标不代表网络流量特征或研究样本。

## 已观察结果

13/26 两种宽度各有 N=1、2、18、32 的变量样本及 N=32 的常量样本；每例评分17行。十例共160棵树、2,198个节点，170/170分数逐位一致，最大绝对差0.0、最大ULP差0。父进程和两个直接子进程均实际退出0；只有一次已放行观察，无重试。

生产端 fit、score_samples、encode 的 attempt/completed 各10；核对端 decode、reencode、score 的 attempt/completed 各10，每例相应计数各1。生产端实际运行过人工模型，不能称本轮零模型。核对端无模型导入、codec导入阶段无NumPy；护栏仅覆盖直接验收程序和高层Python调用，不提供OS/native线程监控。

Python3.14.0、NumPy2.5.4、scikit-learn1.9.1、joblib1.6.0及全部47个被测发行版本与冻结环境一致。两进程使用前批F已接受的安装target，未新安装产品，也没有增加公开导出接口或修改P1算法。当前结果只支持这些固定模型及本环境，另一机器、平台和任意模型的逐位兼容尚未验证。

## 控制器证据缺口

两个子进程的原始stdout均与规范JSON加一个LF逐字节一致，stderr为空。外层工具只保留父进程的一个逻辑成功标记和CRLF文本；未分开捕获原生父进程stdout/stderr，无法核定其精确LF与空stderr条件。该条件保持 `UNVERIFIED`，既不记为通过，也不据此推断原始字节失配。数值范围复核为C0/I0/M0；完整控制器契约为C0/I1/M0，不能称整轮G契约全部通过。

父进程内部10.3251232秒计到收据组装，排除后续原生进程退出；108秒是外层记录推导的保守上界，低于120秒限制，并非精确运行时长。两值均不代表模型延迟、内存峰值或研究成本。原收据、缺口和失败历史保留，没有重建缺失流、重拟合或重跑覆盖。
