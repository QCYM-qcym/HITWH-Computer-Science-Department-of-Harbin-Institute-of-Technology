# 导出字节与本次清单一致

日期：2026-10-30。用途：说明导出最终读取的完整性校验及其限制。接续[保存区间校验](backend-interval-consistency.md)，对应[实施记录](../superpowers/plans/2026-10-30-export-byte-consistency.md)。

旧端点先完成 SavedArtifacts 校验，然后再次读取目标文件直接返回。如果文件在两者之间变化，返回字节可能不属于刚接受的清单。实际确定性反例只替换最后读取的内存结果，旧端点仍返回200；没有改写磁盘旧文件，也不据此声称远程用户能够修改服务器文件。

新实现从本次已验证 manifest 复制三个固定导出项的路径及 SHA 字符串，在完整构造成功后存入独立只读映射。最终读取一次文件，计算所取得 bytes 自身的 SHA，与捕获期望比对后返回同一份 bytes。端点不再打开路径，也不重新读取 manifest 更新期望；单独重新计算路径摘要不能代替对将要返回字节的校验。

scores、metrics、config 的白名单、媒体类型、下载文件名和完整原字节均保持。分页或显示范围不裁剪导出，JSON/Parquet 不重序列化。已取得且校验的原 bytes 即使随后磁盘变化，仍可返回；本修复不新增第三次存在性检查或文件防写锁。

未知任务仍404，未成功任务仍409，非法导出类型仍422。完整包预检继续沿用原错误处理。最终读取时文件消失返回500/EXECUTION_FAILED、details=[RESULT_MISSING]；权限/其他读取错误、截短或摘要不符返回同码且details=[ARTIFACT_INVALID]。错误为普通JSON，不附下载头，不包含原异常文本、私人路径或堆栈。任务历史状态和原产物不改写，不自动重新生成结果。

源码修改限定为 SavedArtifacts、Service 和导出端点：读取结果与原期望绑定，Service 复用现有安全错误映射。生产134/268契约、核心算法、共享样例、前端和真实审计配置保持。此前六项汇总和区间核验继续执行。

本修复仅保证最终导出 bytes 与该次已接受清单摘要相符。较早的文件摘要与JSON/Parquet解析仍可能分开读取，不构成整个目录的原子快照；也不认证作者、模型或分数真实性。不新增全局大小上限、流式协议、缓存或公共manifest字段。
