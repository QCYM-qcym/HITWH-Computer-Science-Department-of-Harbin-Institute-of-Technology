# 输入包检查页运行指南

日期：2026-11-09。状态：源码与限定单元测试已接受，实际安装链验收未完成；首次安装后检查失败，修复后第二轮未启动。下列命令是已实现入口，未作为本轮运行成功证明。关联：[接口与边界](../design/release-input-view-v1.md)、[验证与失败记录](../research/2026-11-09-release-input-view-verification.json)。

这个页面用于查看一个已经保存的准备输入包，显示包身份、六类分钟数量、预处理拟合记录和三种审计政策的资格数量。它消费保存内容，浏览时不运行模型或重新估计预处理参数。

## 启动入口

在已配置 core/backend 依赖的项目环境中，先用输入命令检查准备包：

```text
python -m traffic_anomaly.release_input_cli inspect --prepared-package <ABS_PREPARED_DIR>
```

随后启动独立本地查看服务：

```text
python -m traffic_api.release_input_serve_cli --prepared-package <ABS_PREPARED_DIR> --port 0 --shutdown-after-seconds 120
```

`<ABS_PREPARED_DIR>` 替换为已有准备包的绝对目录。`--prepared-package` 必填；`--port 0` 由系统选择可用端口，也可指定 1—65535 的端口。服务只监听 `127.0.0.1`。`--shutdown-after-seconds` 可省略以保持前台运行，或设为 1—3600 秒；自动关闭计时从就绪事件完整写出后开始。

启动成功时输出一行 `SERVER_READY` JSON，其 `url` 是本次实际地址。使用该地址打开页面，无需上传文件或填写网页参数。正常关闭输出 `SERVER_STOPPED`；事件、启动或关闭错误须结合实际进程退出码判断，不能只看到一条事件就认定整次成功。单独运行 `--help` 可查看固定帮助，不读取包。

## 查看内容

- 输入包和上游分钟包的协议、清单字节数及完整 SHA256，长摘要可展开查看。
- 总分钟、原始有效、预处理有效、共同有效及 H15/H30 历史有效分钟数量。
- 保存的预处理拟合人口及审计拟合政策；模型训练资格另列。
- P_U、P_B、P_A 三列的八类资格，包括训练、独立校准、验证与测试。
- 窗口、特征数、epsilon、配置摘要和保存内容的检查范围。

窄屏三政策表可横向滚动，表格区域可通过键盘聚焦。所有整数 0 保留原值。校准资格为 0 只说明没有符合条件的分钟，不能解释为误报率为 0，也不能据此得到可用阈值。

## CLI 与 HTTP 对照

固定只读接口为 `GET /release/v1/input-summary`；完整响应按协议应与同一包 CLI `inspect` 输出逐字节一致。页面资源固定为 `/release/inputs`、`/release/inputs.mjs` 和 `/release/inputs.css`。接口拒绝非空查询串；未知路径、其他方法及错误响应使用固定安全内容。

服务启动时加载一次包、投影并编码一次摘要、预载三个资源并完成端点上下文预热。正常请求只传输保存字节。页面只发起一次摘要请求，实际响应上限 64 KiB，请求与读体总期限 10 秒；读取失败显示固定说明。检查其他包需结束服务并重新启动。
