# 保存区间与完整分钟核对

日期：2026-10-30。依据[现行片段口径](episode-display.md)，接续[六项汇总校验](backend-evaluation-consistency.md)。本页记录工程保存一致性，不新增研究评价政策。

原实现即使发现不了区间单独篡改，也可能接受合法 Schema 和重新计算的文件摘要。本次让 SavedArtifacts 在同一次纯 evaluate 计算后，先核六项汇总，再精确核 intervals 列表。起止、类型、分钟数、缺项、重复、多余项和次序不一致均拒绝。校验覆盖已经读取的完整分数和独立标签，不受查询分页、筛选或导出参数影响。

精确列表次序对应现有 producer（先误报片段，再未报警攻击片段，各类内部按时间）；这是保存包兼容检查，不是 HTTP Schema 新增的跨类型全局排序保证。旧包若与现有计算不一致会被拒绝，包括仅次序不同的包；保存字节、历史任务状态和旧证据不自动修写。此处不认证来源真实性，也不证明模型分数正确或效果有效。

沿用原始标签轴上的未报警攻击片段：预热或未评分攻击仍可在片段内，但不因此计入逐分钟 FN。全未评分攻击可以有未报警片段、FN=0、召回率=null；部分命中仍保留逐分钟漏报，不作 point-adjust。缺失分钟与缺失标签按既有算法中断片段。原函数没有 segment_id 输入，本改动不新增对相邻时间戳采集边界的识别保证。无标签、空轴、无匹配评价时不伪造片段。

完成前不一致使任务 failed，结果查询为409/RESULT_NOT_READY。成功后读取矛盾包，结果和白名单导出为500/EXECUTION_FAILED、details=[ARTIFACT_INVALID]，历史任务仍为 succeeded。公共错误不含私人路径和堆栈。合法响应使用原保存对象，导出仍是原文件字节；不拿重新计算的对象替换保存结果。

本次不核 high_load_metrics 或说明文字的语义，原说明保持。生产134/268契约、核心算法、共享样例、前端和真实审计配置不变。

实际验证：新增18项回归，修复前10失败/8通过；修复后完整后端100项及原核心片段8项，共108项通过。覆盖区间单独改错、合法预热/全未评分/部分命中/缺口/未知标签/空结果、每次读取只调用一次 evaluate、原响应与导出字节保留。五个旧标签变体正例只同步其临时结果区间，六项汇总断言与原因文字继续检查。保留既有 TestClient 弃用警告。

另实际执行三个全新 FakeExecutor/数据库场景，正常包、完成前区间缩短、成功后区间缩短均符合预期；两组各七个结果入口安全拒绝，三类导出与原文件逐字节一致。故障只改 intervals，六汇总和其他字段不变，Schema 合法且全部 manifest 摘要重新匹配。共有21次纯评价核验；模型库、预处理和模型调用均为0。两个前批运行目录、原详情文件的 SHA/大小/mtime 保持。

以上均为 SYNTHETIC_ONLY 进程内 TestClient 验收，未开监听端口或重跑浏览器、前端构建、无关模型集成及本地全套。真实CSV读取与新增下载为0；真实预处理、训练、评分、Q99和正式实验NOT_RUN，Data Gate BLOCKED。[机器记录](../research/2026-10-30-backend-interval-verification.json)与[实施记录](../superpowers/plans/2026-10-30-backend-interval-consistency.md)提供对应范围。
