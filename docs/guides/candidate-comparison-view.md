# 候选已保存方法的页面对照

日期：2026-11-06。范围：`SYNTHETIC_ONLY / AUDIT_ONLY`。本入口用于核对已有人工运行的共同数据条件和完整测试评价，不选择研究政策或模型。实现与实际验收分别记录，最终验证结果见本批维护记录。

## 启动与查看

完成[环境安装](development.md)，准备相互匹配的人工记录、输入和2—4个不同方法的运行包后，在[原启动命令](candidate-viewer-launcher.md)上增加 `--comparison`：

```text
python -X utf8 -m traffic_api.candidate_serve_cli --records <records-directory> --inputs <inputs-directory> --source-fixture <synthetic-source-json> --if-run <if-directory> --ae-run <current-ae-directory> --ae-run <history15-directory> --ae-run <history30-directory> --comparison --port 0
```

尖括号内容是目录占位，必须替换。命令不生成模型。打开就绪事件中的本机地址后，“同条件方法对照”按固定顺序显示IF当前13维、当前AE13维、历史AE26维H15、历史AE26维H30。允许省略部分方法，缺项显示“未提供”，不会补跑。

未加 `--comparison` 时保留原1—4个运行查看行为，包括同方法多个不同运行；不会调用比较器。显式启用时至少两种方法，重复槽、重复ID、不同上游或不同共同资格均拒绝整个启动，不降级为看起来成功的部分对照。可以省略人工源，但全报告保留 `NOT_PROVIDED`，不能称已核源。

## 页面数值怎样理解

“审计映射”只选择展示原保存的 P_U、P_B 或 P_A；不改变分数来源政策、训练、阈值或原预测，也不构成最终 Attempted 政策决定。各映射分别显示正常、攻击、未知和未评分分钟，再显示各方法原 TP/FP/TN/FN、precision、recall、F1、FPR、FNR。数值0照常显示；不可计算项显示“未定义”及原原因。

共同条件与完整评价独立于单运行选择、曲线时间范围和分页。既有人工示例的全轴144、全轴可评分24、完整测试36、测试可评分6、排除未评分30是不同数量。共同H15/H30资格适用于所有方法，不能用当前13维的名称推断它获得了更多评价分钟。

每种方法的折叠详情保留自己的阈值、分数定义、校准数量、分位位置、等于和严格高于阈值的数量。IF分数与AE误差尺度不同，不能比较阈值大小。当前AE288参数、历史AE509参数，尚未控制容量；IF不解析不透明权重，参数量未定义。页面不排名、不把四种分数叠在同一坐标轴，也不据此宣称历史增强有效。

“重新读取方法对照”只重新取得启动时冻结的报告；不会重读磁盘或重新比较。加载失败时清空该区旧内容，保留其他查看功能。更换结果文件需要停止服务并重新启动准入。

## 数据来自哪里

启动阶段复用[已有比较器](candidate-comparison.md)，其核查包括共同上游、预处理、历史资格和三政策人口。随后将报告中每个运行的五个实际文件摘要、配置、政策、计数及来源检查状态与已经加载的快照逐项绑定。即使运行ID相同，文件摘要变化也不能混用。该绑定检查保存关系，不认证手工构造的对象、模型来源或模型执行。

`GET /candidate/v1/comparison` 返回启动时预序列化的固定JSON，UTF-8载荷含换行不超过1MiB，不接受任何查询参数。未启用时为404及 `COMPARISON_NOT_ENABLED`，非法查询为422及 `INVALID_QUERY`。目录接口的 `comparison_available` 表示是否启用。原生产API/OpenAPI及134/268维契约保持独立。

启用比较会增加原比较器的有界读取：最多4包共128MiB运行包内容及64MiB额外manifest，另有原上游核验；启动器此前的快照加载还须另计。这不是全流程单次读取或总内存保证。全部准入及1MiB响应检查均发生在监听前；HTTP请求仅返回内存报告，不读取源文件、执行模型或重新计算指标。

本功能与[完整单运行评价](candidate-evaluation-view.md)共用已保存的研究口径，仍只用于人工工程。真实文件数值构造、训练、评分、校准和正式比较的状态不能由页面成功改变，研究Data Gate仍为BLOCKED。

## 本批验收

后端相关254项、候选DOM95项通过；全量Python1666项及56子测试通过，两个符号链接权限测试跳过；前端120项、类型/契约/构建和仓库13项通过。独立复审通过。安装包15个源码/资源文件与当前源码逐字节一致。

实际四方法、缺H15、未提供源三次CLI与HTTP字段一致，各服务均定时正常停止、退出0、回收且端口关闭，39个旧文件身份不变。浏览器核对三政策、缺项、弱来源、分页与空范围保持完整分母，390宽度下表格可独立横向滚动。第一次服务的最后一次运行切换发生在定时关闭后，出现预期读取失败；后续仍在服务期内的H30切换成功，无页面错误。此记录不把一次过期请求写成成功，也不将定时关闭当作操作系统信号测试。详见[实际验证记录](../research/2026-11-06-candidate-comparison-view-verification.json)。
