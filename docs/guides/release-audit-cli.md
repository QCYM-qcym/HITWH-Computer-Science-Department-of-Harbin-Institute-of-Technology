# 小预算离线文件审计

日期：2026-11-06。用途：把[有界文件适配](release-file-adapter.md)的读取、精确聚合和诊断作为独立命令使用。新增入口已完成分项测试、独立复审和安装后人工验收，详见[验证记录](../research/2026-11-06-release-audit-cli-verification.json)。当前实际测试仅使用新造人工CSV，真实数据操作仍未获此工程工作自动批准。

```text
python -X utf8 -m traffic_anomaly.release_audit_cli --spec SPEC.json --output ABSOLUTE_NEW_DIRECTORY
```

`SPEC.json`是明确的本地说明文件；输出必须是绝对路径、父目录已存在、目标目录尚不存在。命令不搜索目录、不下载、不训练、不创建候选模型输入包。

## 说明文件

说明为UTF-8 JSON，最多64KiB，顶层只有`version`、`sources`、`segments`和`budget`。拒绝缺键、多键、重复键、NaN/Infinity及错误类型。

| 字段 | 必需内容 |
|---|---|
| version | 整数1 |
| sources | 1—5项；每项恰有`path`、`bytes`、`sha256`，给出源文件、确切非负整数字节数及64位小写十六进制摘要 |
| segments | 1—7项；每项恰有`id`、`role`、`start`、`end`，role为train/validation/calibration/test |
| budget | 下表全部五项，精确整数，不能省略 |

相对源路径以说明文件所在目录为基准，与命令启动位置无关。段时间为不带时区的`YYYY-MM-DDTHH:MM`或秒恰为00的形式；沿既有源钟面解释，不添加UTC或时区认证。段边界须整分钟、顺序合法、不重叠，可有缺口。段ID供内部对应，报告不回显。

| 预算键 | 本入口最大值 | 附加规则 |
|---|---:|---|
| max_total_source_bytes | 8388608 | 源实际总量8MiB |
| max_rows | 10000 | 超额整次失败，不截断后继续 |
| max_database_bytes | 33554432 | 32MiB，至少65536且为4096的倍数 |
| max_elapsed_seconds | 30 | 聚合合作式截止检查 |
| max_minutes | 10000 | 完整登记轴上限 |

预算只能收紧，bool与小数不能冒充整数。30秒不包括说明/报告读写，也不是操作系统硬超时或内存隔离。此小入口不放开底层约210万人口验收时使用的大预算。

先检查普通文件/祖先、路径包含关系、同实体别名、大小、预算和时间轴，再创建输出。禁止父目录跳转、UNC/设备路径、驱动器相对路径、ADS、链接与重解析路径。源之间及源与说明文件不能指向同一实体；同一普通父目录下的并列文件和新输出目录可以。不会先重新计算摘要并将其自动当成预期值。

## 报告与完成条件

全部源在同次读取中核EOF、实际大小和SHA，磁盘聚合成功并清理scratch后，才生成脱敏报告。报告包含实际源凭据、原始/合格/排除/区间外/无法落桶记录数、重复及固定原因计数、各段日历/有效/无效分钟与三政策正常/攻击/未知分钟数，以及实际请求预算和有限资源观察。

原因计数可以重叠，空桶原因计桶，不可相加当作排除记录数。各段政策人口计分钟，不用记录标签计数冒充分钟。主数据库高水位是离散观察，报告不宣称总磁盘或RSS硬限制。

报告不包含路径、原段名、任意原标签、IP/流ID、原始时间轴、查询计划或13维向量。来源始终为`NOT_AUTHENTICATED`，完成时间为`SOURCE_WALL_CLOCK_COMPLETION_PROXY`；这些输出不是已验算候选产物或模型执行授权。

成功目录恰有两个文件：

- `report.json`：最多64KiB的脱敏汇总。
- `COMPLETE.json`：固定版本、COMPLETE状态及报告实际SHA/字节数。

先独占写报告并读回核对，再独占写完成标记。只有两个文件完整可解析、摘要相符且成员集合闭合，才认定完成。仅有文件名或标记字符串不够。未知成员、替换实体、短写、关闭或清理失败都会停止，不递归删除、接管已有目录或自动续跑。

完成标记前的失败保留未完成输出；强杀可能保留scratch。完成后若终端stdout失败，有效报告仍保留，不能仅凭非零退出判断报告一定未完成。此协议不承诺目录原子快照或断电耐久性。

## 返回与使用边界

成功stdout只输出`status=COMPLETE`和`version=1`的JSON，退出码0。失败退出码2，stderr只输出固定安全错误码；存在明确清理失败时附`cleanup_failed=true`，不回显路径、异常说明或堆栈。既有输出目录一律拒绝，修复后使用新目录。

此入口与原JSON记录链、IF/AE执行、生产134/268维契约分别维护。它可以核查声明与文件是否一致，不能认证作者身份、采集完整性、导出延迟、最终标签政策或研究效果。安装验收只覆盖下述人工案例，不代替真实数据准入。
