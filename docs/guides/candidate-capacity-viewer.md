## 使用条件

提供同一固定人工源、记录包、输入包和2—4个已有AE运行包，必须有新当前492及至少一个历史模型。旧当前288、历史H15/H30可按允许组合缺席，页面保留固定四槽并显示“未提供”。各模型使用自己的保存阈值，不按原始分数或阈值排序。

源文件须与运行包记录的实际字节身份相符；LF和CRLF是两组不同身份，不能替换后声称来源相同。准入沿用[参数数量对照规则](candidate-ae-capacity.md)，新模式不接收IF或网页传入的文件路径，不进入旧经典四槽，不重新训练。

```text
python -X utf8 -m traffic_anomaly.candidate_capacity_compare_cli --records RECORDS --inputs INPUTS --source-fixture SOURCE --ae-run CURRENT492 --ae-run HISTORY15
python -X utf8 -m traffic_api.candidate_serve_cli --capacity-comparison --records RECORDS --inputs INPUTS --source-fixture SOURCE --ae-run CURRENT492 --ae-run HISTORY15 --port 0 --shutdown-after-seconds 120
```

上述大写项是本地路径占位符。完整组还可加入当前288和历史H30；只读服务固定监听127.0.0.1，port 0分配空闲端口。按READY事件的实际URL访问`/candidate/capacity`。定时参数只请求正常关闭，不是进程树硬时限。

## 共享输出与隔离页面

CLI和`GET /candidate/v1/capacity-comparison`共用确定性UTF-8字节：按键排序、紧凑JSON、末尾一个LF、含LF最多1MiB。读取运行包、核保存关系、比较及编码在启动阶段完成；请求返回冻结内容，不打开运行包、重评分或重算指标。上层准入调用一次不等于所有上游源只被读取一次，快照不可变也不认证模型来源。

另外三条固定GET为`/candidate/capacity`、`/candidate/capacity.mjs`和`/candidate/viewer.css`。查询键拒绝为422，非GET方法拒绝为405，未知路径404，内部失败投影为固定安全500；不启用任意静态目录、上传、任务、导出或生产路由。缺源或来源不符在监听前拒绝。完整组实际检查覆盖200/422/405/404；故障500与HEAD边界由冷进程测试覆盖，二者分别记录。

页面依次展示当前288、当前492、历史H15/509、历史H30/509。三政策仅切换已有值，不改变最终政策，不重新发起评价。全轴144、共同有效24、测试36、可评分测试6和未评分测试30分别标注。0、未提供和不可计算分开；precision为空时保留“没有带标签的正预测分钟”原因。

详细配置、来源身份和精确保存值可展开；失败或重试清除旧结果，Abort与请求代次阻止过期结果覆盖当前状态。响应按实际流字节计量，不能信任Content-Length。窄屏采用表格内部横向滚动，页面本身不溢出；实际完整组已核键盘滚动和可见焦点。

17/509约3.34%小于预设5%，只说明参数数量接近；不证明有效容量、优化难度或分数尺度相同，也不能据此归因历史信息改善。实际人工包保留完全漏报负例：各行TP/FP为0，P_U的TN/FN为4/1、P_B为5/1、P_A为4/2；FPR0、FNR1、precision为空，不作为效果结论。

## 首次失败与修复边界

第一次安装服务验收中，四条GET即使返回200，严格守卫仍捕获四次打开端点源码的尝试，因此该次整体失败。根因是锁定FastAPI 0.156.6首次请求时惰性提取错误上下文，经inspect/linecache读源码；不能只看HTTP状态宣告请求零文件访问。

修复在容量app工厂返回、监听之前，调用框架已有上下文提取函数预热四个实际endpoint。不修改框架全局函数、不直接写缓存、不放宽守卫或更改经典模式。冷进程测试先复现1项失败，再1项通过；修复后435项相关回归通过，独立审查及三个启动探针通过。该私有框架接口属于锁定版本兼容接缝，未来升级须重跑冷进程与安装验收。

修复后重新构建并安装59个核心及20个后端文件，使用现有锁定依赖环境，没有下载依赖，不称全新依赖环境或异机复验。完整组再次执行：CLI与HTTP的20763字节完全相同，三资源原字节一致，请求阶段守卫零文件/模型动作尝试，正常退出、回收和端口关闭；原67项人工产物、旧安装58文件及独立新492包5文件保持。完整组与492＋H15子集浏览器均有独立实际观察收据；子集12573字节CLI/HTTP全等，并正常停止、回收、关闭端口及通过最终身份检查。两组各7个脚本请求，共14个，不包含浏览器请求数量。子集288/H30缺席，三政策与展开H15证据、重试保留P_A均已观察；窄屏仅对完整组另行验证。
