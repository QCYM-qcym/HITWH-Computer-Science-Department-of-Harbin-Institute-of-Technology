# 合成任务解释通道的时间与字段绑定

日期：2026-10-30。状态：SYNTHETIC_ONLY 修复。范围仅 FakeExecutor 新产物；[公共契约](../design/contracts-v1.md)、共享 fixture、前端及真实执行器均未改变。

旧 writer 将首条 MinuteDetail 的通道复制到所有分钟。统一样例只提供 00:01、00:03 的显式详情，00:00、00:02 因此出现未提供的当前特征。修复后按详情自身的时间戳匹配，缺项四通道为 null；不按详情顺序拼接，也不以评分有效性决定当前特征是否存在。

| 样例分钟 | 评分状态 | 显式详情 | 修复后存在的通道 |
|---|---|---|---|
| 00:00 | 预热、不可评分 | 无 | 无 |
| 00:01 | 有效 | 有 | current |
| 00:02 | 有效且报警 | 无 | 无 |
| 00:03 | 有效 | 有 | current |

这只是该手工样例的提供情况。若显式提供预热分钟的 current，仍应保留；score、threshold、alarm 则继续为 null。历史偏离与两类重构通道保持各自独立的可空语义，不能补零或复制其他分钟的值。

## 实现与兼容边界

所有显式详情先经 MinuteDetail 验证，字段顺序必须与 RunSummary 精确一致，拒绝错序而不自动重排。随后仅提取四个 Channels 字段，输出顺序和时间仍取自 scores。重复显式时间戳拒绝；合法轴外详情验证后忽略，无详情时允许全空通道。标签文件继续来自独立 core_sample，不取详情标签构造特征或替换标签源。

既有 IF 重构通道限制、写入后完整性检查与最终 rename 保持。校验失败进入 failed，查询返回公共安全错误；未完成目录不是成功产物。仅新生成的合成包改变 channels 及对应摘要，旧目录不重写，读取路径不自动修复历史内容。运行 ID、配置、字段顺序与清单摘要检查不等于模型执行或来源真实性认证。
