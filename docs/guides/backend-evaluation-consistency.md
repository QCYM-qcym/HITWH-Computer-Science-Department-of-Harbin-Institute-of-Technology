# 后端保存评价汇总核验

日期2026-10-30；本页对应[实施记录](../superpowers/plans/2026-10-30-backend-evaluation-consistency.md)，范围为保存产物消费，不改变研究评价协议或生产契约。

问题：Evaluation能验证给定混淆矩阵自身的比率和覆盖率，却不知道保存分数与标签。原后端只核Schema、清单摘要和身份，因此结构合法、摘要一致的错误汇总也可能成功展示。例如已有人工样例实际包含一次误报和一次漏报，另存“TP=1、FP=0、TN=2、FN=0”的汇总仍满足其自身Schema。

核验使用已经读取的完整分数与标签行，复用核心纯评价函数；只比较available、metrics、normal_coverage、attack_coverage、excluded_attack_minutes、background_only_minutes六项。分钟连接、主要攻击/背景/正常候选和无标签口径不变，模型不执行、阈值不重新校准。HTTP与导出仍提供原保存对象和文件字节，不用核验结果替换它们。

任务完成前不一致会进入failed，公共错误沿用EXECUTION_FAILED；未成功任务的结果查询返回409。成功后发现重新封装摘要的矛盾产物，结果查询及白名单导出返回500/EXECUTION_FAILED，details为ARTIFACT_INVALID。历史任务状态不回退或自动改写；本地日志可定位验算失败，公共错误不含路径或堆栈。

标签缺失或没有匹配分钟时，不补正常标签，评价保留NULL和原因。无正常或无攻击分母时，各指标沿用既有未定义表达。仅有背景标签不进入主要评价；背景与主要攻击重叠沿用主要攻击口径。页面分页与时间筛选不会改变完整保存分钟上的核验。

本批范围限制：不比较intervals、high_load_metrics或说明文字。原统一fixture漏报片段为00:01–00:02/1分钟，核心函数包括前一无效攻击分钟为00:00–00:02/2分钟，片段排序也不同。这一既有差异仍待按原契约单独核对，不在汇总修复中暗改样例或定义。高负载口径未放行，不能把本次六项检查称为所有片段/高负载结果已认证。

验证只用SYNTHETIC_ONLY人工样例与隔离临时运行目录、数据库；真实数据可用性、模型效果及正式比较不由这些检查证明，Data Gate保持BLOCKED。


[实际验证](../research/2026-10-30-backend-evaluation-verification.json)：有效RED12失败/7通过，修复后76项相关测试全部通过（新19、原后端50、集成7），独立审查通过。相关集成包含既有合成IF/当前AE/历史AE执行。另三个无模型FakeExecutor场景完成正常12项检查及两组各7路由安全拒绝，原导出字节与fixture保持；只用进程内TestClient，未开监听端口或进行浏览器验收。现存TestClient弃用警告保留记录。
