# 发布格式解析与分钟聚合

日期：2026-11-06。用途：候选数据适配开发。内部实现、独立复审及安装后的人工验收已完成；真实载荷处理、真实特征矩阵和模型运行仍为 `NOT_RUN`。

这两个内部模块补上完整91列CSV到13项分钟统计的计算步骤。本轮输入全部由人工构造，旧134/268维生产契约保持独立。解析对象明确标记 `NOT_AUTHENTICATED`；文件摘要和行指纹只用于一致性核对，不认证来源、采集完整性或操作授权。

## 入口与边界

[_release_csv.py](../../src/core/traffic_anomaly/_release_csv.py) 的 `_parse_release_csv(sources, *, budget)` 接收不可变bytes元组，返回冻结的源摘要和解析记录。[_release_minutes.py](../../src/core/traffic_anomaly/_release_minutes.py) 的 `_aggregate_release_minutes(parsed, segments, *, max_minutes)` 返回完整登记分钟轴、13项数值、三种审计标签及计数。

本批没有文件发现、命令行、写包或模型入口，也没有把任意输入自动转成 `SYNTHETIC_ONLY` 的桥接。仅在测试辅助代码中，将已明确人工构造的分钟结果接入既有预处理和H15/H30历史计算。内部函数可以接收调用方提供的bytes，这种接口范围本身不构成授权防护。

| 边界 | 本批上限与行为 |
|---|---|
| 源 | 1—5个bytes对象，累计8MiB；调用方可收紧预算 |
| 记录 | 总计10000条，单字段4096字符；超额整次失败 |
| 词汇 | Label、Attempted Category、Protocol原词分别最多100、32、256种 |
| 整数 | 数学非负整数；展开最多4096十进制位，转换前检查 |
| duration | 微秒整数，最多86400秒；超过既有护栏或完成时间溢出即停止 |
| 登记轴 | 1—7段、最多10000分钟，整分钟、左闭右开、按时间排序且不重叠 |
| 临时磁盘 | 0字节；完整批次仍保留在内存，不是常量内存流式处理 |

对象数和输入大小上限不是操作系统内存硬限制。此实现不支持直接接入约210万条真实记录；扩容需另行实现和验证。

## 记录身份与数值规则

表头逐项匹配[既有91列配置](../research/2026-10-24-c17-g13u-config.json)，不容忍改名、重排或缺列。CSV使用UTF-8-sig与严格解析。每个解码字段的UTF-8长度和内容参与完整行SHA-256；`1`与`1.0`数值可以相同，但词法身份不同。CSV引号或行尾编码变化若不改变解码字段，行指纹保持，源文件摘要仍可能不同。id或Flow ID不单独作为重复键。

时间保留无偏移源钟面，按 `Timestamp + Flow Duration` 的名义完成时刻归入分钟，不添加Z，也不宣称实际导出时刻或在线可用。Protocol0保持独立未解析通道与原标签；其他协议资格、Label与Attempted Category联合解释沿既有规则。未使用列的NaN或Infinity只留下诊断，不删除整行。原字段保留在解析对象中以支持身份核对，但不进入其repr或安全错误信息。

全部输入先按完整行身份统计重复，每个重复副本均排除；区间外行也参与这一步。完成时刻在登记范围外的记录单列排除，不污染其他分钟。跨段记录只污染其完成桶，同为test的不同日段也视为不同段。无法确定完成时刻的坏时间或duration污染完整登记轴；空桶保持无效未知，不补零或视为正常。

合格记录与有效分钟分别计数：同桶出现一个非法协议记录时，其他好记录仍可计入eligible，但该桶不能产生有效向量。满足 `raw = eligible + excluded`，原因允许重叠。桶内UNKNOWN优先于attack，再normal；未知标签本身不破坏可计算数值。三种Attempted映射保留为并列审计，未选定最终政策。

13项顺序见[候选数值说明](candidate-inputs.md)。计数和duration先保留整数；用完整duration样本计算median及linear P95，rank分别为 `(n−1)/2`、`19(n−1)/20`，有理插值后才转秒与float。最终浮点可能舍入，尤其计数超过2⁵³时；不能有限表示则整次失败，不改成普通源记录排除。无效桶在Python接口返回13个None（空值）及固定原因，不生成零向量。

## 验证与后续

人工夹具为[完整91列JSON](../../tests/fixtures/release-91-artificial-v1.json)；CSV字节在测试中生成，不包含真实源行。相关测试为[解析测试](../../tests/core/test_release_csv.py)和[分钟测试](../../tests/core/test_release_minutes.py)。可在已有环境执行：

```powershell
.venv\Scripts\python.exe -X utf8 -m pytest tests/core/test_release_csv.py tests/core/test_release_minutes.py -q
```

测试覆盖手算向量、精确微秒分位、乱序、完整重复组、Protocol0、跨段与全域污染、标签与数值分离、历史重置及资源错误。人工预处理拟合只使用人工训练正常资格；不运行IF/AE模型。新增解析154项、分钟73项；分钟/解析/既有输入记录联合277项通过，解析与旧审计联合206项及22子测试通过，两组有重叠，不能相加。解析大指数资源分类问题在独立审查后修复，窄复审15项通过；分钟及跨模块复审通过。

后续优先实现有界文件读取与磁盘精确聚合，在人工负载上检查一次源读取、完整SHA绑定、晚到重复、精确分位及故障清理。只有实际人工规模验收通过，才能登记对应容量；真实操作仍需匹配已明确的研究决定和运行范围。Data Gate保持BLOCKED。


安装后的51个核心源码文件与冻结版本逐字节一致，在仓库外调用人工样例通过。四行手算向量、全副本重复排除、污染桶eligible保留及无法落桶全域污染均核对；144分钟人工轴的三政策当前正常测试供给为5/6/5，历史数值和共同24分钟保持一致。

独立人工一万行集中单桶，输入2708075字节，解析加聚合本机观察约0.410秒，Windows进程峰值工作集78635008字节；人工2439分钟七段轴及历史链路约0.277秒、峰值工作集60522496字节。峰值包含解释器、依赖和夹具构造；这是本次进程观测，不是通用性能、RSS硬限额或真实规模验收。七段人工正常测试共同供给1839与真实审计1831分别保留，不能互相替代。

首次安装手工验收的I/O守卫拦截了NumPy延迟导入；在守卫前初始化既有NumPy后重跑通过，没有修改产品代码。完整失败及验证边界见[本批验证记录](../research/2026-11-06-release-format-verification.json)。
