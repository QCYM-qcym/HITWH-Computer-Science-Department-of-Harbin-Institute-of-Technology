# 开题报告 V0.3 到 V0.4 修改说明

日期：2026年10月9日。当前版本供学生与导师审阅；没有开展数据下载、模型训练或实验。

## 修订依据与边界

以学校开题模板八栏目为最高结构依据，结合所供理工类书写范例与现有研究记录。新任务明确要求适度扩写背景，覆盖上一轮“背景一句话”的表达偏好；研究范围没有因此扩大。保留工作题名、现有四项研究问题、UGR16 FeatureData的优先候选角色和原型辅助定位。V0.1—V0.3、原始两份.doc与复杂路线图均保留。

## 主要修改

| 位置 | V0.3的问题 | V0.4的实际修改 |
|---|---|---|
| 1.1 | 背景只有一句，问题缘由不充分 | 以昼夜、周内业务、负载、周期任务及长期变化说明正常背景的变化；解释偏离不必然是攻击；将规律存在与收益保留为假设 |
| 1.2 | 目的混入数据步骤、三基线、窗口、实验与产物 | 压缩为一个自然段，只说明研究对象、比较目标和时间信息的作用 |
| 1.3 | 意义与实施路径混合 | 分两段说明研究解释价值和异常分析应用价值，不夸大贡献 |
| 2.1—2.4 | 按国内/国外逐篇点评，并多次立即接“本课题” | 改为统计与机器学习、深度表征、时间信息与适应、数据与评价四条路线；在论点中联合引用多篇文献，国内外工作嵌入对应路线 |
| 3.1—3.5 | 工程任务拆分、逐项“产出为” | 改为五个研究主题，每节两个自然段，保留对象、对照与分析目标，删除脚本和模型文件交付清单 |
| 3.3与4.3 | “历史残差增强自编码器”接近既定最终方案 | 改为时间信息增强候选；输入增强或评分辅助由数据与基线决定，最终基本范围仍为一种机制 |

| 5 | 周计划含过程管理与检查点语言 | 保留相对24周六阶段，用文献、数据、基线、方法实验、原型和论文描述；不虚构学校截止日 |
| 7 | 枚举式风险登记表达 | 改为数据、正常异常混淆、历史污染、无收益、资源五个自然段；保留对应措施与负结果可能性 |
| 8 | 需要跟随综述结构更新编号 | 16篇全部保留，按首次出现重新编号；补入Kitsune作者稿可核实的正式DOI |

## 表述变化举例

- “产出为三个检测器、训练与评分脚本、模型文件……”改为讨论三个评分机制及其在正常变化中的行为差异。工程记录要求保留在研究方案与原型实现材料中。
- “历史残差增强自编码器将当前分钟特征……”改为“初步考虑利用滑动时间窗口……具体表示方式和窗口长度将在数据可用性检查及基线实验后确定”。
- “禁止随机打乱……禁止用全量……”改为“为减少时间信息泄漏……缺失处理与缩放参数仅根据训练数据估计”。
- 不把正常周期、方法增益、创新性和资源速度写成已验证结论，没有增加性能数字或复杂模型。
