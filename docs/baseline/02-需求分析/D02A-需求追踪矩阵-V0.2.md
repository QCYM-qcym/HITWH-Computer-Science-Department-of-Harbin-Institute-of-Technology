## 共用证据包与当前状态

每项测试执行时必须记录：对应Test ID、数据集及版本/输入哈希、代码与配置版本、随机种子、原始输出、复核记录及运行状态。原矩阵中的Evidence字段对所有行使用同一证据包规则，因此在此集中定义，避免重复挤占表格空间。当前25项（17项FR、8项NFR）全部为`DESIGNED / NOT_RUN`：表示追踪、测试与验收已设计，尚未实现或运行；不代表测试通过，也不代表已发现缺陷。

## 追踪状态规则

`DESIGNED / NOT_RUN`表示设计结构及验收已登记，未实现/未执行；`PASS`须有Test ID、代码/配置版本、输入哈希、原始输出与复核记录。负结果可满足“执行/报告”验收，但不能伪装为效果提升。Candidate Fusion若最终不独立存在，先提交变更同步FR-009、RQ4、图、测试和论文映射。
