# 项目作图规范

版本：V1.0；生效日期：2026-10-09。

适用于本项目开题报告、毕业论文和答辩材料中的架构图、拓扑图、ER图、流程图、模型图、实验设计图及结果图。用户本轮要求将已采用的视觉规则存入作图规范；以已交付的柔和配色 Visio V2.1 十图为样例。后续作图默认遵循本规范，用户当前明确要求及学校正式版式要求优先。

## 配色

白色画布，浅色填充区分模块，深灰文字保证可读性。同一组图中，相同模块或方法保持同色；颜色之外同时使用名称、线型或标记表达含义，使灰度打印仍可辨认。

| 用途 | 色值 |
| --- | --- |
| 浅蓝填充 | `#D9E8FB` |
| 淡紫填充 | `#E2D5E7` |
| 薄荷绿填充 | `#F3FEF6` |
| 暖黄填充 | `#FFF5C4` |
| 待核验或异常提示的淡粉填充 | `#F7CECC` |
| 蓝色边框/连线 | `#527A9B` |
| 紫色边框/连线 | `#877293` |
| 绿色边框/连线 | `#528373` |
| 黄褐色边框/连线 | `#9B824C` |
| 淡粉提示边框 | `#A26967` |
| 标题文字 | `#202329` |
| 正文文字 | `#414750` |

每张图按实际模块选用其中几种颜色；在图例中说明具有业务含义的颜色。结果曲线可使用上述较深的线色，并配合不同线型或点形。

## 字体与字重

| 元素 | 默认字体 | 字重 |
| --- | --- | --- |
| 中文标题及标签 | 微软雅黑 / Microsoft YaHei | 标题加粗，正文常规 |
| 英文标签、缩写及字段 | Arial | 模块标题加粗，正文常规 |
| 数学公式及变量 | Times New Roman | 按数学含义设正斜体及粗体 |

中英文混排分别指定西文和东亚字体。公式中的粗体向量等符号保持语义；逐项检查上下标、希腊字母和特殊符号，必要时为缺字指定兼容字体。参考截图中的 Comic Sans MS 保留为风格参考，不作为当前正式学术图的默认字体。

## 字号与线条

复用 V2.1 场景脚本时，采用以下源画布单位；这些数值是参考坐标中的像素单位，**不是 Word/Visio 的 pt 字号，也不是学校规定字号**。

| 层级 | V2.1 参考值 |
| --- | --- |
| 主标题或重点标签 | 34–36 |
| 面板标题 | 32 |
| 模块标题 | 26–30 |
| 正文标签 | 24–28 |
| 辅助说明 | 24 |
| 普通形状边框 | 1.8 |
| 主连接线 | 不超过 2.4 |
| 密集网络中的细连接线 | 约 1.3 |

新图先确定最终插入尺寸，再按比例调整字号和线宽；同级元素保持一致。以报告实际插入大小和答辩投影大小检查可读性，文字拥挤时优先缩短标签、换行或拆分图，而非持续缩小字号。图注按学校模板在正文排版，避免图内外重复标题。

## 布局与局部模块

- 先安排整体分区、阅读方向和数据流，再绘制局部模块；同级模块对齐并等距留白。
- 采用统一的框形、圆角、箭头尺寸及内边距；模块标题、正文和辅助说明形成清楚的层级。
- 连线以短且清楚为目标，避免穿过文字；需要区分数据流、控制流或可选分支时，明确标注线型含义。
- 复杂图按面板与局部模块分组，子元素保持在父容器范围内；实体关系标明基数，拓扑图区分逻辑连接和物理部署。
- 参考图借鉴布局、配色和信息表达，项目内容以当前报告与设计资料为依据。候选方案、合成示意与真实结果分别标注；状态和指标必须有来源。

## 制作、导出与验收

1. 项目架构、拓扑、ER、流程及模型结构图优先使用 Visio 原生形状、文字、连接线与分组，保存可编辑 `.vsdx`；结果数据图可使用科学绘图库并保留数据及绘图脚本。
2. 修改已有图时另存版本或备份。仅修改样式的任务须核对文本、节点关系及连线方向，保留其原意。
3. 保存源文件后重新打开，导出 SVG、PDF 和 PNG。报告素材默认提供宽 4800 像素、600 dpi 的彩色与灰度 PNG；按实际插入宽度检查有效分辨率，优先使用矢量版本。
4. 每张图检查文字截断、重叠、字体替换、模块越界、箭头方向和灰度可辨性；PDF 逐页检查，不能仅检查文件是否存在。
5. Visio 交付检查原生形状与文本，确认没有用整页位图代替可编辑图；若交付 PPTX，说明其中对象的实际可编辑范围。
