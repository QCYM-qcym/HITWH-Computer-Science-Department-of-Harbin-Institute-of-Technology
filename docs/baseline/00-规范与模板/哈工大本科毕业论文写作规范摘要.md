# 哈工大本科毕业论文写作规范摘要

依据：哈尔滨工业大学本科生院《本科毕业论文（设计）写作指南（理工类）》，2022年10月。原件：学校指南（原始附件保留本地）。以下仅提取原文规则，不推定其为2026年最新修订；专业或校区另有要求时应核对。

| 主题 | 原文规则提取 | 位置 |
|---|---|---|
| 题目 | 一般不超过25字，中英文对照；尽量避免不常用缩写、代号和公式 | 1.1 |
| 主副题 | 字数合计不超过35字；中文用破折号，英文用冒号相连，除此之外不能含标点；各处保持一致 | 1.1 |
| 摘要内容 | 独立、自含；包含目的、意义、内容、方法，重点为成果与结论；完整客观准确，不遗漏、不拔高、不添加；一般第三人称 | 1.2.1 |
| 摘要禁用项 | 不宜使用公式、图表、非常用缩写等，不标注引用文献编号 | 1.2.1 |
| 摘要长度与语言 | 中文一般300字左右；中英文内容完全一致，各占一页，中文在前；摘要页不写论文题目 | 2.3 |
| 关键词 | 3至6个，外延从大到小；中英文一一对应；中文分号、英文逗号分隔 | 1.2.2、2.3 |
| 正文结构 | 绪论、论文主体、结论 | 1.4 |
| 绪论 | 课题来源、背景、意义、国内外进展及不足、分析框架、研究内容、程序和方法；准确标引；主要研究内容宜用将来时，不得直接照搬目录 | 1.4.1 |
| 主体 | 结构严谨、层次清晰、数据可靠；叙述实验条件与过程，不能直接给结果曲线；区分他人成果和本人分析 | 1.4.2 |
| 本章小结 | 主体各章后应有本章小结，实验方法或材料等章节可不写 | 1.4.2 |
| 结论 | 单独排写，不加章序，不标引文；一般400至2000字，不能与摘要混同 | 1.4.3 |
| 字数 | 专业确定具体要求，一般正文不少于1.5万字，含图表 | 2.1 |
| 文献数量 | 一般不少于15篇，外文一般不少于3篇；近五年一般不少于总数三分之一，应有近两年文献；特殊专业可明确另定 | 1.5 |
| 文献口径 | 所有被引文献入表，同篇一个序号；尽量原始来源；网页和标准不计入上述数量；本人学位期间论文不列入参考文献 | 1.5 |
| 标引规则 | GB/T 7714—2015，顺序编码，正文引文一般右上角方括号编号；直接说明文献编号时与正文排齐；标题不放引文号 | 2.6、2.14 |
| 层级 | 目录编至章、节、条三级；正文每章另页，标题一般15字以内、不加标点；层次统一，以少为宜，标题不得在页末最后一行 | 2.4、2.5、3.7 |
| 表格 | 有自明性，不加左右边线，建议三线表；表前正文提示；表题在上，按章如表1-1编号，序与名空2个半角字符，中文宋体5号，表名无标点 | 2.12 |
| 续表 | 一页放不下才续页，右上注明编号及续表，重复表头；不用同上符号；引用表在正文和表题标来源 | 2.12 |
| 插图 | 文图一致、清晰完整、精练自明；数据及程序流程图依指南所引GB/T 1526—1989；无规定采用行业通用画法；坐标图注明单位 | 2.13 |
| 图题 | 图题在下，中文宋体5号，按章如图1-1编号；序名间空2个半角字符；图注在图题上；引用图标出处 | 2.13.1 |
| 图文编排 | 图前必须正文提示；图及图题不可拆到两页；分图用a、b等标识，续图按规则标注 | 2.13.1、2.13.2 |
| 图表字体 | 宋体和Times New Roman，尽量5号，较多可小5号，单个图表内一致；物理量符号斜体 | 2.12、2.13.1 |
| 公式 | 另行居中、按章编号如（1-1），编号右对齐；引用见式；较长式优先等号转行；首次变量注明含义 | 2.11 |
| 字体与字号 | 正文宋体小4，英文数字Times New Roman；章黑体小2、节黑体小3、条黑体4、款项黑体小4；正文1.25倍行距，段前后0 | 3.1、3.2 |
| 纸张与版心 | A4；版心150mm×240mm±2mm，含页眉页码；每页约33行；单面印刷，学校统一封皮 | 3.8 |
| 页码与页眉 | 文前罗马数字单独编排，正文起阿拉伯数字；页码居中；除封面内封有指定页眉及粗细双线 | 2.2、3.4 |
