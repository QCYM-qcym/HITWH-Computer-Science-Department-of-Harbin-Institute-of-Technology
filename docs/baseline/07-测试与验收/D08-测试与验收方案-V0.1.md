# D08 测试与验收方案

版本：V0.1　日期：2026-09-24　状态：设计草案，待评审

本轮仅进行设计与文档化；未开展数据下载、模型实验或业务实现。题名为WORKING TITLE，模型、数据版本和性能指标尚未冻结。

## 1 测试策略
Unit Test覆盖数值、排序、窗口及契约；Integration Test覆盖特征至评分至存储；Data Validation按D03；Model Validation验证学习式评分与资源；Experiment Reproducibility检查版本和重复运行；API Test在服务选型后覆盖状态、校验和权限；System Test覆盖UC-01至08；Performance Test使用固定规模与预热；Demo Acceptance包括离线降级；Research Acceptance以可追溯RQ证据为准。
## 2 功能测试目录
| Test | 前置与输入 | Procedure | Expected Evidence |
|---|---|---|---|
| TC-FR-001 | 版本清单与原始文件 | 核验路径、哈希和格式，拒绝不支持输入，同时构造相应非法输入 | 正确文件可登记；损坏文件可重现失败；保存实际输出与断言 |
| TC-FR-002 | 已登记原始数据 | 检查缺失、Inf、重复与单位，保存处理规则，同时构造相应非法输入 | 处理前后数量可核对；不静默丢行；保存实际输出与断言 |
| TC-FR-003 | 事件时间及记录标识 | 校验时区与单位，稳定排序并报告重复和断点，同时构造相应非法输入 | 逆序样本被识别；同刻排序可复现；保存实际输出与断言 |
| TC-FR-004 | 有序记录与窗口配置 | 仅使用当前记录之前已可用历史，标记预热，同时构造相应非法输入 | 未来记录不影响当前窗口；预热有标识；保存实际输出与断言 |
| TC-FR-005 | 划分清单与字段定义 | 仅训练集拟合缩放、编码和特征选择，同时构造相应非法输入 | 测试统计量不进入拟合；字段错序被拒绝；保存实际输出与断言 |
| TC-FR-006 | 特征批与基线配置 | 执行统计及Isolation Forest对照，同时构造相应非法输入 | 分数方向统一；同协议可核对；保存实际输出与断言 |
| TC-FR-007 | 训练特征或模型产物 | 训练、加载并推理轻量学习式检测器，同时构造相应非法输入 | 模型重载前后评分在预定容差内一致；保存实际输出与断言 |
| TC-FR-008 | 当前特征与过去状态 | 计算历史偏离或合格时间上下文，同时构造相应非法输入 | 已知小样本可手工复算；不读取测试标签；保存实际输出与断言 |
| TC-FR-009 | 同一记录两路分数与校准配置 | 统一尺度、按预定规则组合并阈值判定，同时构造相应非法输入 | ID不一致拒绝融合；权重边界与预热策略有测试；保存实际输出与断言 |
| TC-FR-010 | 逐条检测结果与分组规则 | P0生成告警记录；事件合并需显式规则，同时构造相应非法输入 | 每条告警追溯到分数、模型与输入；保存实际输出与断言 |
| TC-FR-011 | 运行ID、时间范围 | 查询完整或明确标记的部分结果，同时构造相应非法输入 | 空范围返回空集合；失败结果不冒充完成；保存实际输出与断言 |
| TC-FR-012 | 版本、种子与实验配置 | 校验依赖，创建运行并维护状态，同时构造相应非法输入 | 失败、取消、完成明确区分，重试另留记录；保存实际输出与断言 |
| TC-FR-013 | 固定预测及独立标签 | 计算混淆矩阵和分类指标，检查未定义值，同时构造相应非法输入 | 手算样例一致；单类别及零分母标N/A；保存实际输出与断言 |
| TC-FR-014 | 可比运行集合 | 检查切分、单位、标签口径并比较，同时构造相应非法输入 | 不同切分不直接拼排行；负结果保留；保存实际输出与断言 |
| TC-FR-015 | 冻结检测和评价产物 | 绘制时间曲线、分数与告警，显示版本，同时构造相应非法输入 | 显示值与产物一致；标签和推理输入分离；保存实际输出与断言 |
| TC-FR-016 | 有序记录、模型或历史结果 | 支持暂停与继续，明确实时重算或结果回放，同时构造相应非法输入 | 重放顺序一致；展示模式明确且可离线运行；保存实际输出与断言 |

## 3 非功能测试目录
- TC-NFR-001：Performance。吞吐、耗时、内存和显存预算TBD；Phase 2固定输入规模、预热及测量方法后确定门槛。证据：资源日志及固定规模复测。
- TC-NFR-002：Reliability。无效数据、缺失产物、失败与取消均显式反馈；部分结果不写完成状态。证据：故障注入与恢复记录。
- TC-NFR-003：Reproducibility。固定数据哈希、种子、配置、环境及代码版本；容差先登记。证据：独立重复执行与指标复算。
- TC-NFR-004：Maintainability。模型、预处理、决策和展示分离；契约变更有版本。证据：模块职责与接口一致性审查。
- TC-NFR-005：Extensibility。新增检测器遵循同一契约，不改变存储核心字段语义。证据：替代检测器契约测试。
- TC-NFR-006：Traceability。任何指标和告警均可回溯运行、模型、切分及记录。证据：抽查产物引用链无断链。
- TC-NFR-007：Usability。研究与核查两类操作有清晰状态及失败说明，未知值不显示为零。证据：UC-01至08走查。
- TC-NFR-008：Security。只读取授权本地路径；不保存密钥，不暴露原始敏感标识，不自动响应攻击。证据：路径越界、脱敏、日志和访问边界检查。

## 4 验收关卡
所有Gate当前NOT_RUN；以下为计划，不是执行结果。
### DATA_GATE_PASS
Entry Criteria：版本候选与许可入口。

Procedure：执行D03五步审计及小规模解析资源核验。

Evidence：文件哈希、字典、时间和标签报告、切分。

Exit Criteria：DATASET_READY且解析预算可接受。不满足即保持未通过并登记问题，复验保留原失败。

### BASELINE_PASS
Entry Criteria：DATA_GATE_PASS。

Procedure：同协议运行统计和IF，手核分数与指标。

Evidence：配置、预测、指标与资源日志。

Exit Criteria：基线闭环可复现且无泄漏。不满足即保持未通过并登记问题，复验保留原失败。

### AI_MODEL_PASS
Entry Criteria：BASELINE_PASS及候选模型配置。

Procedure：训练、重载、评分并测资源。

Evidence：模型、损失、重载测试、资源证据。

Exit Criteria：学习式模型可复现运行，分数可评价；不要求优于基线。不满足即保持未通过并登记问题，复验保留原失败。

### TEMPORAL_METHOD_PASS
Entry Criteria：AI_MODEL_PASS及适用时间机制。

Procedure：验证历史因果、校准和融合，对照单分支。

Evidence：窗口测试、融合配置和首轮消融。

Exit Criteria：时间方法行为正确、可重复并具备评价条件；无增益可通过实现门槛但须记录研究结论。不满足即保持未通过并登记问题，复验保留原失败。

### EXPERIMENT_PASS
Entry Criteria：方法、矩阵和评价协议冻结。

Procedure：执行对比消融敏感性效率动态评价。

Evidence：完整运行集合、图表及负结果。

Exit Criteria：RQ有可追溯答案，公平性与局限得到报告。不满足即保持未通过并登记问题，复验保留原失败。

### SYSTEM_PASS
Entry Criteria：必要FR实现及冻结模型产物。

Procedure：端到端、接口、故障、离线Replay与资源验证。

Evidence：测试记录、Demo版本、缺陷处置。

Exit Criteria：P0需求无未处置阻断缺陷，输出与实验一致。不满足即保持未通过并登记问题，复验保留原失败。

### FINAL_ACCEPTANCE_PASS
Entry Criteria：EXPERIMENT_PASS和SYSTEM_PASS。

Procedure：核对研究成果、论文规范、任务书与展示。

Evidence：论文检查、追踪矩阵、导师评审记录。

Exit Criteria：学校和导师要求确认满足；未知要求不得自动通过。不满足即保持未通过并登记问题，复验保留原失败。

## 5 缺陷与研究失败
运行错误、数据不合格和研究假设不成立分别登记；无增益不等于系统故障，不能为Gate通过修改测试标签或选择性删除负结果。性能阈值TBD，在Phase 2测量后与可用工期共同冻结。
