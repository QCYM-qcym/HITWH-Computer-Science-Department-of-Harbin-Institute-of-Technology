# 历史残差候选实现说明

版本：V0.1　日期：2026年10月9日　状态：待数据与基线验证

本说明保留开题报告V0.3中较细的计算和实现安排，作为既有《研究内容与技术方案》的补充。它不是新的算法选型决定，也不替代数据检查和基线实验。V0.4正文只保留核心残差与重构评分示例，最终采用输入增强还是评分辅助形式仍待确定。

## 历史残差与数值处理

对训练数据拟合变换后的当前向量uₜ，在此前H个有效连续分钟内逐特征计算中位数mₜ,ⱼ和中位绝对偏差dₜ,ⱼ。残差为rₜ,ⱼ = (uₜ,ⱼ − mₜ,ⱼ)/(dₜ,ⱼ + ε)，其中ε为正数。H、ε及尺度处理依据训练和验证数据确定。

V0.3曾考虑对残差按验证阶段确定的上下界截断，记为c(rₜ)，再组成zₜ = [uₜ, c(rₜ)]。维数由p变为2p，异常分数采用平均平方重构误差。V0.4用不展开截断的拼接示例说明核心思想；是否截断、处理范围和具体实现均待验证。不能把两份文档中的示例差异解释为已经完成算法改进。

## 状态与时间边界

每分钟读取既有历史，构造残差并评分，然后将当前记录加入窗口。各数据区段独立预热，时间缺口处重置历史；所有检测方法在相同有效分钟上评价。历史更新不根据测试标签筛选正常记录。连续异常影响历史统计的情况纳入污染分析。

## 对照及实现记录

输入增强示例与原始自编码器比较时，采用相同隐藏层设置和验证搜索范围，记录输入维数增加导致的参数量差异。另设仅使用历史残差的统计评分，以分析深度表征的作用。独立融合消融仅在最终方法具有独立组合规则时开展。

数据版本与文件校验值、字段清单、划分边界、数值处理、模型设置、随机种子、软件版本和硬件条件继续由软件工程与实验记录管理。检测评分和评价标签保持分离，原型回放沿用实验配置。这些是待实施的记录要求，不表示模型、接口或实验已经运行。
