# PHASE 0 文档生成与质量检查记录 V0.1

## 检查范围与方法

六份正式正文、独立导师评审包、学校规范摘要共八份 DOCX。每份均由 WPS 原生打开并导出 PDF，再按页渲染为 PNG 进行目视检查；同时检查 OOXML 字体声明、内嵌图像数量、图集文件及 Markdown 图链接。默认 LibreOffice 转换器不可用，因此采用 WPS 完成转换与分页核查。

中文正文为宋体小四（12 pt），西文及数字为 Times New Roman；中文标题按层级使用黑体。图中文字优先中文，SVG 字体栈包含 Times New Roman 与宋体。使用标题样式导航；本版不含动态目录域。
