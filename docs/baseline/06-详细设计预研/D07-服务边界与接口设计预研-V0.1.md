# D07 服务边界与接口设计预研

版本：V0.1　日期：2026-09-24　状态：设计草案，待评审

本轮仅进行设计与文档化；未开展数据下载、模型实验或业务实现。题名为WORKING TITLE，模型、数据版本和性能指标尚未冻结。


## 1 设计范围
先定义交换语义、职责与失败，不冻结REST路径、JSON字段拼写或服务拆分。P0允许同进程调用或产物文件交换。
## 2 信息契约
| 边界 | Input | Output | Responsibility | Failure Mode |
|---|---|---|---|---|
| Data Processing → AI Detection | FeatureBatch：记录ID、字段版本、单位、可用时间、数值矩阵 | ScoreBatch：ID、模型版本、分数及方向 | 校验字段与训练/推理一致性，不传测试标签 | 维度错序、NaN、模型未加载，拒绝评分 |
| AI Detection → Fusion | AI分数、记录ID、模型及校准版本 | 已对齐评分引用 | Fusion与Temporal结果按ID对齐 | 缺失/重复ID、不同检测单位，拒绝融合 |
| Temporal → Fusion | 时间分数、历史范围、预热状态 | 可用上下文 | 明确是否允许冷启动退化 | 时间逆序、未来历史、错误状态版本 |
| Fusion → Anomaly Event | 联合分数、阈值、判定、模型与配置引用 | 告警记录 | 一条判定可追溯；合并事件需另有规则 | 缺依据、重复写入，幂等键或冲突错误 |
| Experiment Engine → Result Storage | RunManifest、模型、预测、指标、日志引用 | 持久化回执和完整性状态 | 完成发布前校验产物；失败保留部分状态 | 磁盘不足、哈希失败，run不得完成 |
| Backend → Frontend | 运行与时间范围查询；启动请求为受控配置 | 状态、指标口径、分页结果和图表数据 | 后端执行校验，前端只展示 | 不存在、不可比、运行失败、分页过期，显式响应 |

## 3 核心对象
DatasetManifest记录来源、许可、哈希和时间说明；FeatureBatch记录schema和检测单位；ModelArtifact记录模型及变换；RunManifest记录配置、种子、状态和产物；DetectionRecord保存两路分数、历史范围、阈值和判定；EvaluationRecord独立关联标签及指标定义。
## 4 一致性与错误语义
run_id和record_id联合追踪；契约版本不兼容即拒绝。RUNNING结果可只读浏览但必须标部分结果，只有COMPLETED进入正式比较。重试不覆盖原运行。幂等键为候选设计，具体持久化机制后续细化。
## 5 安全与权限边界
本地导入限制授权目录，不将任意路径直接拼接读取；模型产物只加载可信来源。前端不接触训练标签处理逻辑与秘密配置。真实设备标识脱敏；本项目不提供自动封禁接口。
