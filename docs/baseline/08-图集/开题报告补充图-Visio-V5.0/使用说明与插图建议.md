## 内容核对与科学边界

1. 补图01将FaaC的单位明确为流记录条数，各维之和不是总流量；七组维数为6、104、5、6、3、5、5，合计134。图中8类标签是独立评价资料，不接入特征输入。地址类别和端口统计不能逆向恢复端点访问关系。
2. 补图02的DoS、扫描与僵尸网络迹象均来自V0.20待检验论述，没有把线索画成攻击的充分条件。SCAN11与SCAN44仍分别计算召回，模型输出为分钟级二分类，而不是四分类器。
3. 补图03区分当前134维、USAD的134×(H+1)窗口、增强AE的268维输入。USAD直接/串联重构以及其训练机制不等同于普通AE；保留原始全窗口分数并另行计算末端分钟分数。历史增强的总体评分与原始字段解释使用的当前通道误差分别处理。
4. 补图04只使用当前分钟之前的连续有效历史。历史不足或时间缺口需预热/重置，先评分后更新。各时间分段独立预热；不会使用未来记录补当前缺失。训练样本可信正常条件与测试历史真实更新方式遵循报告。
5. 补图05中的同宽度比较不足以单独证明历史收益，因此包含相近参数预算的当前AE对照。特征删减同时改变输入维数与参数量，结果表明依赖而非攻击机制的因果证明。v3/v4比较须对齐后进行，不能预设某版本更好。99%分位校准对应预设1%正常误报目标，不是测试集FPR保证；测试不用于反复筛选字段或调阈值。高负载口径按V0.20预先固定的TCP/UDP训练正常分位点定义，不对134列求和。
6. 补图06为解释方式设计，没有虚构报警计数或指标。历史残差按绝对值取前五，同时保留正负号；当前特征误差单独排序。增强AE残差通道误差另列；独立攻击标签在回放中明确标作评价依据。该MAD历史残差与文献均值/标准差的U-Squared离线诊断分别命名，不混同。偏离字段是统计线索，不等于攻击来源。
7. 补图07区分分钟级首版与条件性原始流扩展。IP基数、实际包字节总量和速率必须由原始NetFlow重新计算；“取得片段”本身不意味着时间/版本/配置已对齐。未取得可靠输入时不承诺主机定位。
