## 可以直接使用的文件

- `png/`：4800 像素宽、600dpi 的彩色和灰度 PNG，适合插入 Word。含“预览”的 1200 像素图片只用于查看。

建议在 Word 中以嵌入型、居中方式插入高清 PNG，宽度 15—16cm，锁定比例。图题置于图片下方，沿用学校格式。原 V0.7 Word、原生公式与历史图集未修改；本轮没有创建插图后的报告新版。

## 方法语义说明

图2的历史窗口仅使用当前分钟以前 H 个有效连续分钟，残差公式按各特征逐项计算。
训练用表示先沿完整时间序列构造，再筛选可信正常且窗口有效的当前分钟；避免删除异常记录后制造连续历史。
验证和测试先评分与报警，再将当前预处理特征加入窗口，评价标签不参与历史更新。区段独立建立历史，预热或缺口重置后在共同有效分钟评价。
各方法共享正常误报控制目标与校准规则，分别使用其自己的阈值；首轮测试固定模型与阈值。
拼接是首个候选，不代表最终方法冻结；H、ε、尺度处理与模型参数待数据及基线验证。
图3的延迟仅在标签可靠定位事件起点时统计，并说明分钟粒度；完整条件仍以报告4.4为准。
不绘制未运行的性能曲线、结果柱图或提升比例。

## Visio 环境限制与重建入口

本机未检测到注册的 `Visio.Application`，因此未运行 Visio COM、未生成 `.vsdx`，也没有完成 Skill 要求的“从已保存 Visio 源文件导出”流程。本包 SVG/PNG 是从统一几何场景直接绘制的可用替代产物，不能称为完整 Visio 重建验收通过。

安装 Microsoft Visio 后，可在 Windows PowerShell 执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\sources\generate_visio.ps1
```

脚本会从三份 JSON 绘制 Visio 原生矩形、文本、连线与语义分组，保存到 `visio/`，再由保存后的 Visio 页面导出 SVG 和 PNG。再次运行时备份同名 `.vsdx`。
此脚本仅完成 PowerShell 语法检查，未经过 Visio 运行或渲染验证；Visio 字体、文本基线和分组行为仍需在安装后的预览中检查。它不会把当前 SVG 或 PNG 作为整张图片嵌入 Visio。
