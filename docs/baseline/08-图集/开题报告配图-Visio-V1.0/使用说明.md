# 开题报告原生 Visio 图集 V1.0

使用 Microsoft Visio 16.0 COM 与 visio-image-rebuilder Skill 实际绘制，共15页。文字、方框、箭头、线条和分组均为原生可编辑对象；文件内无整页位图。适用于开题报告插图和后续设计讨论。

## 文件使用

- `开题报告-15图原生Visio图册.vsdx`：主文件，在 Visio 底部切换页面。单击选择分组，进入组内或取消组合后编辑细节；连接线为原生线段，移动模块后可能需要手工调整端点。
- `pdf/开题报告-15图图册.pdf`：15页矢量审阅版。
- `svg/`：从保存并重新打开的 Visio 主文件导出的矢量图。
- `png/*-4800px-600dpi.png`：从 Visio PDF 渲染的高清彩色与灰度图，宽4800像素，600dpi元数据；按8英寸宽插入时为600dpi。
- `png/*-Visio原生导出.png`：Visio 自身直接导出的检查图；`*-预览.png`为快速预览。
- `sources/`：对象布局、候选实体字段、绘制与导出脚本、结构核验记录。绘制脚本仅生成源文件；再单独运行导出脚本。

## 依据与设计身份

主要依据：开题报告《开题报告-项目作者-V0.9》、系统概要设计HLD V0.2和ADR-004“数据库暂不冻结”。最新开题稿优先。图中部署为单台Windows电脑上的本地离线研究原型；模块代表逻辑职责，不表示已实现独立服务。SQLite只作为可选轻量索引。

ER图为本轮提出的候选逻辑设计，包含9类实体、字段、主外键和基数，不代表数据库已经实现或选型冻结。`ID/Time/Real/TimeRange`为逻辑类型，尚未转为数据库DDL。特征、模型等大对象保存在文件中，实体记录版本与路径。

## ER关系和约束

所有关系按“父实体 : 子实体”阅读；除分钟特征到标签为1:0..1，其余均为1:0..N。

- DatasetVersion → TimeSplit、MinuteRecord：分别通过 dataset_version_id。
- TimeSplit → ModelBundle：通过 fit_split_id，记录拟合与校准所依据的时间划分；该划分同时保存训练、验证和测试范围，拟合与校准只能访问允许的部分。
- TimeSplit → ExperimentRun：通过 split_id，表示运行所用划分。ModelBundle → ExperimentRun：通过 bundle_id。
- ExperimentRun → Artifact、Prediction、MetricResult：通过 run_id。
- MinuteRecord → MinuteLabel、Prediction：通过 record_id。
- Prediction 的复合主键为 (run_id, record_id)；MinuteRecord 的 (dataset_version_id, timestamp) 唯一。
- MinuteLabel.record_id 同时是主键和外键，标签缺失与正常标签应区分；仅样本核验和独立评价读取标签。
- 运行、模型、分钟记录须通过划分/版本校验保持来源一致；当前外键图不足以自动保证此跨表约束，实施时需补应用校验或数据库约束。
- 有效性为false的预热分钟不记作正常预测，score/alarm可为空；有效分钟必须提供分数与报警。seed、配置、阈值和产物哈希用于复核。

## 研究边界

训练、验证、测试按时间划分；处理参数只在训练段拟合；阈值在验证段单独校准并固定用于测试；历史仅来自过去，先评分后更新，时间缺口触发重置与预热。实验和回放共用核心逻辑，方法切换重载配置并重置状态。没有加入虚构实验数值，配图完成不表示研究实验已完成。
