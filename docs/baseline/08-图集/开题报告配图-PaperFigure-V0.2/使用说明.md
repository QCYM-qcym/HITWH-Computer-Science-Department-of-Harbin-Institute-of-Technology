## 文件说明

- `png/`：11张彩色高清PNG、11张灰度高清PNG，4800像素宽、600dpi；另附11张1200像素预览。
- `svg/`：11张可编辑SVG，保留文字、框图与箭头，无整图位图嵌入。
- `sources/`：统一几何JSON、Visio绘图脚本、许可与核验记录。
- `新增8图总览.png`：本次8张图的预览索引，便于快速挑选；排版时使用每张独立高清PNG。

Word建议以嵌入型、居中插入，锁定比例，宽15—16cm。图题放下方并沿用学校要求。图中的主标题、解释与约束可供答辩展示；若正文配合已有图题，可在SVG中按需要删去重复主标题。

## 科研语义

所有新增图都是研究方案示意，不包含未运行的准确率、性能提升或实验曲线。
数据版本与标签身份需核验；标签仅用于训练样本核验与独立评价，不作为检测特征或历史更新输入。
训练、验证、测试按时间划分，各区段独立建窗；处理参数只在训练区段估计；验证选择参数和各自阈值，测试固定模型及阈值。
历史更新先评分后加入当前记录，记录不足预热，时间缺口重置。消融解释同时考虑输入维数、评分机制与模型容量。
图08中的误报校准目标不等于已经达到的测试误报率；历史统计对照应使用同一校准规则，图中四条线展示主对比方法。

## Visio限制

本包交付SVG和PNG，不包含VSDX。此前未检测到Visio COM，本轮未运行Visio绘图；SVG/PNG由统一几何直接渲染，不能称为从Visio母版导出或完整Visio验收通过。
`sources/generate_visio.ps1`可在已安装Microsoft Visio的Windows环境中绘制全部11张原生可编辑图并导出。该脚本仅通过PowerShell语法检查，未在Visio中运行验证；安装后的文本与分组仍需预览核验。

```powershell
powershell -ExecutionPolicy Bypass -File .\sources\generate_visio.ps1
```
