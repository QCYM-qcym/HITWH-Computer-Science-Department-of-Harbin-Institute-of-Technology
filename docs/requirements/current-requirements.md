# 当前需求 V1

用途：W0-01 开发输入。日期：2026-10-21。状态：依据开题稿建立的实现基线，未取得新的导师审阅或研究 Gate 通过记录。依据：[报告 V0.40](../reports/开题报告-V0.40-公开文本.md)、[实施计划](../superpowers/plans/2026-10-21-parallel-development.md)。历史需求保留于 baseline。

研究问题：近期历史能否降低正常分钟和正常高负载分钟的误报，以及会否增加攻击漏报与成本。比较对象为 IF、当前 134 维 AE、当前与历史偏离各 134 维的联合输入 AE；同宽度与参数量接近的当前 AE 分别控制容量。效果未知，允许负结果。

系统范围为本地单用户、离线分钟检测和保存结果回放。Python 共享核心由 CLI 和 FastAPI 调用，Vue 页面只展示已有产物，不重算研究指标。首版单 worker；有 queued/running 任务时拒绝新任务。失败留原因，重启中的 running 标失败，重试建立新 ID。取消任务与在线检测延期。

输入限已登记 UGR16v3 分钟特征。134 个真实字段顺序在 Data Gate 确定；合成 feature_000 等名称不代表真实字段。标签另存八数组，dos/scan11/scan44/botnet 为主要攻击，背景四类单列；全零仅为正常候选。未知时区、冲突、缺失不能静默填零。保留提供方测试范围，开发范围分训练、验证、独立校准三段；实际边界待数据审计。

预处理、模型、窗口和阈值只使用允许的开发区段。训练正常候选拟合 log1p 后的 StandardScaler；该变换作用于完整原始时间轴，再在每段构造先前连续 H 分钟的中位数/MAD 历史偏离。无效行、缺口和切分重置历史。训练与校准仅用当前及所需历史均正常候选的共同分钟；测试历史不消费测试标签。epsilon 必须为正且记录，15/30 分钟为候选窗口，验证后固定；这些实现选择尚未经过真实数据验证。

当前 AE 以 134 维均方误差评分，增强 AE 对 268 维均分，两通道等权。各方法分数越大越异常。独立校准段共同正常分钟各方法自身分数 99% 分位点（linear）为阈值，严格大于才报警。空集或非有限校准分数应失败。主要指标基于共同有效分钟，报告分母、覆盖率及排除攻击。零分母显示 null 和原因，不做整段命中扩展。高负载组在五协议计数经核验后采用训练正常流记录数 90% 分位点，否则不可评价。

页面支持数据、任务、分析和比较，明确合成/真实身份。报警与完全未报警的攻击片段都可定位；当前值、历史偏离、逐字段重构误差分开显示，缺通道为 null。导出完整分钟的 scores、metrics、config 白名单文件。任意服务器路径、原始标签特征和未完成产物不能通过请求泄露。

验收：计算边界及人工样例、保存重载、故障与恢复、CLI/API/页面一致性、同条件研究评价和部署复现。W0 的契约测试与 CPU 小张量检查只算 SYNTHETIC_ONLY；真实数据、模型效果、系统功能验收仍 NOT_RUN。开题实际反馈、投入预算及资源门槛待登记。

逐项变更及七项目标见[需求追踪](traceability.md)，字段与接口见[契约](../design/contracts-v1.md)。
