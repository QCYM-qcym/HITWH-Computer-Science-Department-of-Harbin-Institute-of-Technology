# 隐私与发布规则

公开版本使用通用项目角色，不填写真实姓名、学号、个人邮箱、电话号码、私人账号、导师或同学身份、沟通截图及本机个人路径。论文作者与公开出版信息属于研究引用，保留其来源。

## 发布前检查

- 检查文件名、正文、路径、链接、配置及提交作者。
- 图片审查画面内容；Office/PDF审查正文、隐藏内容、备注、批注、修订、作者属性、缩略图与嵌入资源。
- 凭据、环境文件、原始流量、模型权重、第三方缓存、个人知识库和沟通记录留在本地。
- 在本地配置 `privacy.local.json` 可增加姓名、标识等禁止项；该文件由Git忽略，不在公开仓库中列出具体值。

检查工具阻止已知个人目录、邮箱、手机号码、学生编号字段、常见凭据模式及未支持的二进制文件。它不是通用脱敏证明；未匹配的姓名和图片内容仍需审查。

本仓库提交使用通用维护身份与非个人邮箱。GitHub仓库地址和账号归属由平台展示，文件内容匿名不意味着平台层面的完全匿名。

发现已发布的个人信息时先停止继续推送并定位受影响版本，新增脱敏修复；涉及历史重写或删除远端内容时另行确认具体处理范围。不要通过新的README掩盖历史中的泄漏。
