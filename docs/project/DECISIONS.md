# 公开决策与方案差异

## 2026-10-31 候选已验证运行结果快照

采用[候选运行快照](../guides/candidate-run-snapshots.md)为后续分钟消费者提供已验证载荷；不新建验证规则、产物格式或生产契约。根对象不是认证凭证，直接构造只接受普通JSON字典；加载后保留分数文档延长其内存生命周期，副本另占内存。Attempted、主数据和真实实验批准不变。

## 2026-10-30 后端五类JSON共用已核字节

采用[JSON单文件字节绑定](../guides/json-byte-consistency.md)。五个manifest管理的正式调用都传本次原SHA，根manifest没有上级摘要，保留类型读取而不假称认证。旧helper两参兼容保持；摘要不符在parser前拒绝，包括解析结果相同的合法空白变更。原digest循环、业务规则和错误映射保持，不新增公开字段/大小上限，不扩原因或高负载语义、core读取及研究政策。

## 2026-10-30 后端三类Parquet共用已核字节

采用[单文件字节绑定](../guides/parquet-byte-consistency.md)，三种同构Parquet使用一个helper，正式SavedArtifacts都传本次manifest原SHA；None默认只保留无manifest的旧直接setup兼容。原digest循环保留，后一次取得的bytes同时核验及解析。记录额外编码buffer的峰值成本，不新增公开字段/大小上限；JSON和core独立loader暂不扩大，研究政策不变。

## 2026-10-30 导出以本次接受清单为准

[导出最终字节](../guides/export-byte-consistency.md)必须匹配本次已验证manifest捕获的原SHA，返回同一份已核bytes，不再次读取路径或清单刷新期望。保留原完整文件和headers；读取失败映射为现有安全错误，不改历史状态，不修写旧包。本工程决定不新增资源上限/流式协议/公共字段，也不声称完整原子快照或来源认证；真实研究批准边界不变。

## 2026-10-30 保存区间精确匹配现有评价输出

采用[区间一致性检查](../guides/backend-interval-consistency.md)：在六项汇总后复用同次纯计算，精确比对保存intervals，包括列表次序。合法响应与导出保持原字节；不一致旧包安全拒绝，不迁移或修复历史产物。此决定是保存兼容约束，不改原标签轴、预热、缺口、FN及无point-adjust口径，也不把producer次序扩写为HTTP Schema全局排序保证。高负载语义与研究批准边界不变。
