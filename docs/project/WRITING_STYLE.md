# 报告与 PPT 文字规范

生效日期：2026-10-13。状态：用户指定的默认文字风格基准。适用于后续报告正文、PPT 标题与页面文案、讲稿和演讲者备注。

## 默认基准

使用 [lieflat-less-ai-tone](https://github.com/larashero3-dotcom/lieflat-less-ai-tone) 检查成稿中的模板化表达。当前采用的 [SKILL.md](https://github.com/larashero3-dotcom/lieflat-less-ai-tone/blob/27d29232f10124db904ca9c0536d0b67cb3b2833/SKILL.md) 对应提交 `27d29232f10124db904ca9c0536d0b67cb3b2833`，许可为 MIT。项目保留完整技能资源及安装记录，第三方原仓库保持本地。

用户当前要求和学校正式模板优先；视觉设计沿用[项目作图规范](../baseline/00-规范与模板/项目作图规范.md)。文字检查服从学术报告体裁和已有论证，不以口语化或缩短篇幅作为合格标准。

## 应用步骤

1. 按当前任务完成内容核验及结构、版式调整，区分计划、候选方案和真实结果。
2. 锁定此轮成稿的内容与结构，读取指定 Skill，逐条检查其明确列出的触发标记。仅对命中的文字做解决问题所需的最小改动；判断不明确时保留原文。
3. 对照检查前的版本核对事实、数据、专业术语、公式、引用及限定词。每处改动都应能对应 Skill 的规则；未命中的文字逐字保留。
4. 导出后检查文字可读性、换行、截断和备注。文字变动引起排版变化时，按照原模板调整布局。

内容修改或结构调整来自用户的具体任务，文字风格检查放在这些修改完成之后。后续制作或修订报告、PPT 时默认执行该步骤，无需用户再次点名 Skill。

## 报告与幻灯片的具体要求

- 报告保持正式、准确的学术表达。章节编号、交叉引用、必要术语和引文服从模板及原文功能。
- PPT 保留标题层级、页序、并列要点、表格和图中标签。句法整齐本身不足以修改承担比较或步骤功能的要点列表。
- 讲稿保持可朗读的表达及原有论证；演讲者备注中的事实、数据与页面一致。针对时长压缩内容须属于具体任务范围。
- 只按上游明确列出的规则处理翻案句式、提示性空话、冗余复述和其他命中表达。正常问句、必要排比、长句或被动句不因主观“AI 感”改写。
- 保留“可能”“拟”“待验证”等限定词，不将计划写成完成，不增加未经材料支持的例子、效果或结论。

本规范是语言编辑基准。最终质量仍通过内容、来源、方法和排版检查评估；文本风格统计不用于判定作者身份或证明学术合规。
