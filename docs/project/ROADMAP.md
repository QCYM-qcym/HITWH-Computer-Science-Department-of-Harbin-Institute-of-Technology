## 下一批工作

1. 整理评审反馈；将最新开题提案与既有需求、概要设计及验收矩阵对齐。
2. 确认数据版本与使用许可，编写数据审计计划。阶段启动以实际授权和评审记录为依据。
3. 数据通过后实施最小基线，先得到可重载、可评分、可测资源的闭环。
4. 基于基线证据再推进历史方法和展示系统；漂移/在线更新以及大模型应用保留扩展身份。

## 维护周期

每次完成相关工作更新受影响文档、检查文件分区和隐私，通过 GitHub Desktop 提交并推送。阶段结束复核路线图状态和证据链接；文档稿与可运行程序使用不同版本标识，未实现阶段不标记为完成。
