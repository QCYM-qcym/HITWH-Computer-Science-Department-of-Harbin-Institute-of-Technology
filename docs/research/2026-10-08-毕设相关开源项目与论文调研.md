## 2. 逐项核验与使用建议

### 2.1 UGR16_FeatureData：最先解决数据与时间结构

**已核验事实。** [作者实验室下载页](https://codas.ugr.es/animalicos/en/downloads)直接链接 [josecamachop/UGR16_FeatureData](https://github.com/josecamachop/UGR16_FeatureData)，因此官方来源关系有一手依据。它主要是特征数据资源，并非训练框架。当前根目录实际有 `csv/`、`matlab/`；README 还提到 Excel，但本轮根目录未见 Excel 文件夹。[仓库 README](https://github.com/josecamachop/UGR16_FeatureData/blob/main/README.md)列有时间戳 `obs_l/obs_lt`、日内分钟 `classM/classMt`、日期及工作日/周末字段，并说明 Y 是每个观察内各类攻击的计数；这些描述针对 MATLAB 数据，不能假定 CSV 也带同样元信息。

[正式 Data 2025 论文](https://www.mdpi.com/2306-5729/10/3/33)说明 FaaC 将流量聚合到 1 分钟、134 个特征：v1 包含六月训练数据；v2 排除六月；v3/v4 又涉及双向/单向流等处理差异。因此，衍生版本变化会改变训练背景和检测对象，不能把不同版本结果当模型公平对比。配套 [UGR’16 原论文作者稿](https://nesg.ugr.es/nesg-ugr16/dataset_AuthorVersionFinal.pdf)与 [大学存档](https://digibug.ugr.es/handle/10481/55280)支撑原始数据的周期性研究背景，不能证明本地候选载荷的连续性与周期强度。

**许可与可得性。** [仓库 LICENSE.txt](https://github.com/josecamachop/UGR16_FeatureData/blob/main/LICENSE.txt)为 GPL-3.0；[2025 论文作者稿首页](https://digibug.ugr.es/bitstream/10481/102834/1/data-10-00033.pdf)另写 Dataset License: CC-BY-NC。两项声明应分别登记，不应将仓库 GPL 自动解释成所有数据可无条件再分发。已确认 [CSV 文件目录](https://github.com/josecamachop/UGR16_FeatureData/tree/main/csv)与 [MAT 文件目录](https://github.com/josecamachop/UGR16_FeatureData/tree/main/matlab)可读取；本轮未下载或打开数据内容。README 的 Data 论文题名/年份仍是早期记录，引用应采用正式版：José Camacho、Rafael A. Rodríguez-Gómez，2025，Data 10(3):33，DOI [10.3390/data10030033](https://doi.org/10.3390/data10030033)。

**本课题建议。** 先以小规模载荷审计选版本：核验 CSV 与 MAT 行号、时间戳、X/Y 对齐、缺失分钟、重复时间、攻击计数转二分类的规则，以及六月训练污染。若删除观察导致间隔不均，不能把相邻行直接等同于相邻分钟。优先比较 v2/v3/v4 的用途与时间保留情况，再决定主版本；不能先挑表现最好的版本。可在开题“数据选择依据/风险”部分引用两篇论文，在实验中将数据版本固定并记录其预处理来源。

### 2.2 scikit-learn：最稳妥的 Isolation Forest 实验起点

**已核验事实。** [scikit-learn 官方仓库](https://github.com/scikit-learn/scikit-learn)为 BSD-3-Clause；[IsolationForest 官方文档](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.IsolationForest.html)明确其输入为样本×特征矩阵，并引用 Fei Tony Liu、Kai Ming Ting、Zhi-Hua Zhou 的 2008 Isolation Forest 论文。原论文可从 [作者主页 PDF](https://cs.nju.edu.cn/zhouzh/zhouzh.files/publication/icdm08b.pdf)读取，DOI [10.1109/ICDM.2008.17](https://doi.org/10.1109/ICDM.2008.17)。官方实现的 `score_samples`/`decision_function` 越低越异常，`predict` 异常标为 -1，正常标为 +1；这与一些其他库的评分、标签方向不同。

**本课题建议。** 用 CPU 建立 IF 对照，保留连续分数，统一为“越大越异常”的项目评分约定，再由相同校准协议生成告警。采用时间顺序训练/验证/测试，训练区间拟合预处理与 IF，验证区间校准阈值，测试区间只评估。IF 不自动建模时序；若加入时段、滞后或窗口统计，应记录为时间增强 IF。它能为 RQ2 提供传统 ML 参照，也能回答 RQ3“时间信息是否有益”，但不能把树模型异常分数直接解释成攻击概率。数据仍需外部接入，不是仓库自带 UGR’16 实验。

**难度与资源评估。** 低至中；原生 API 与文档较完整，适合作为最先 Smoke Test 的模型。Windows 依赖安装、数据规模下耗时和峰值内存仍未验证；采用正式发行版并固定版本，避免直接以开发分支作为实验环境。

### 2.3 PyOD：用统一接口建立轻量 AE 对照

**已核验事实。** [yzhao062/pyod](https://github.com/yzhao062/pyod)为 BSD-2-Clause；[2019 JMLR 论文](https://www.jmlr.org/papers/v20/19-011.html)直接指向该仓库，作者为 Yue Zhao、Zain Nasrullah、Zheng Li，JMLR 20(96):1–7，预印本 [arXiv:1901.01588](https://arxiv.org/abs/1901.01588)。当前 README 已描述 PyOD 3 与可选 agent/LLM 工作流，2019 论文不是当前每个组件的版本说明。[当前 AutoEncoder 源码](https://github.com/yzhao062/pyod/blob/master/pyod/models/auto_encoder.py)使用 PyTorch，支持隐藏层、批量、训练轮数和设备选择；异常分数越高越异常，默认 `contamination` 还参与二值阈值定义。

**本课题建议。** 只选经典本地 detector API，先取一个小全连接 AE，与统计/IF 比较；不把 LLM 模型选择、agent 工作流或多模态功能加入 P0。AE 架构、训练轮数、预处理、随机种子与分数方向写入统一 Detector 契约；阈值单独校准，避免库默认 `contamination` 造成不一致的告警预算。UGR’16 的分钟聚合特征可作为候选矩阵输入，但 AE 同样不天然知道日内或跨窗口顺序。添加时间信息、时间残差或融合只能作为后续可检验变体。

**难度与资源评估。** 中；轻量 AE 在当前资源上值得最小试验，但“8GB 显存足够且已可运行”没有证据。建议先 CPU 验证评分链路，再实测 GPU；固定发行版、PyTorch/CUDA 与设备信息。未核验自带网络数据，UGR’16 管线需自行设计。引用 PyOD 论文只说明实现工具，不能替代 AE 方法或所选时间增强机制的文献依据。

### 2.4 Kitsune-py：网络专用 AI 与时间特征的重要参照

**已核验事实。** [ymirsky/Kitsune-py](https://github.com/ymirsky/Kitsune-py)是论文作者 Yisroel Mirsky 的实现，MIT 许可；[NDSS 2018 会议页面](https://www.ndss-symposium.org/ndss2018/accepted-papers/)与 [arXiv:1802.09089](https://arxiv.org/abs/1802.09089)核对了题名和四位作者：Yisroel Mirsky、Tomer Doitshman、Yuval Elovici、Asaf Shabtai。[README](https://github.com/ymirsky/Kitsune-py/blob/master/README.md)描述 AfterImage 时间衰减增量统计、KitNET 小 AE 集成及 RMSE；输入是 pcap/pcapng/解析后 TSV，特征按包生成。代码有特征映射/检测器训练宽限期；README 明确 Python 版未达到论文速度，历史测试环境为 Anaconda 3.6.3/Windows 10。根目录含 `example.py` 与 `mirai.zip`，完整数据另给外部链接，未下载核验。

**本课题建议。** 精读其“时间统计 → 特征映射 → 小 AE → 分数”链路，开题中解释网络深度异常检测已有基础，也据此收紧原创表述：时间信息 + AE 本身已存在。若 UGR’16 成为主数据，只移植 KitNET 到聚合矩阵属于改编，必须声明特征提取器和检测单位不同；不要称完整复现 Kitsune。若另用包级 Kitsune 数据，宜作为补充实验，分别报告单位、训练宽限期与时间覆盖。它捕获局部网络统计上下文，不等同于按小时/工作日的正常周期基线。

**难度与资源评估。** 中至高；模型轻量并不消除 pcap 解析、旧依赖与单位对齐成本。优先阅读，再判断是否加入复现；不承诺现代 Windows/Python 环境即装即跑或论文实时性。

### 2.5 Telemanom：借鉴动态阈值，谨慎迁移整套 LSTM

**已核验事实。** [khundman/telemanom](https://github.com/khundman/telemanom) README 对应 Kyle Hundman 等的 KDD 2018 论文，[arXiv:1802.04431](https://arxiv.org/abs/1802.04431)，DOI [10.1145/3219819.3219845](https://doi.org/10.1145/3219819.3219845)。方法针对 SMAP/MSL 航天器遥测，利用 LSTM 预测误差、非参数阈值与误报缓解。[README](https://github.com/khundman/telemanom/blob/master/README.md)约定每条通道为 `.npy` 时间序列；原数据时间匿名化，并描述按测试集 min/max 预缩放。当前下载步骤指向需要账号/API key 的 Kaggle 镜像，本轮未确认镜像载荷与原版一致。[requirements.txt](https://github.com/khundman/telemanom/blob/master/requirements.txt)仍固定 NumPy 1.17.4、Keras 2.3.1、TensorFlow 2.0.1 等旧版本。

**许可核验。** README 称 Apache 2.0，但 [实际 LICENSE.txt](https://github.com/khundman/telemanom/blob/master/LICENSE.txt)是 Caltech Copyright Assertion，列有保留声明、二进制附带声明、禁止未经许可背书三个条件，GitHub API 未识别为标准 Apache 许可。本轮保留该不一致，不仅凭 badge 将许可写成 Apache-2.0。

**本课题建议。** 重点研究“模型分数如何成为告警”和阈值对误报的影响，设计固定阈值与时间校准阈值的公平对照。不要将航天器结果视为网络检测收益，也不要沿用测试集缩放到 UGR’16。其批处理阈值流程若移植为在线版本，必须核验决策时是否使用当前时刻之后的误差，明确“处理完一段后告警”与“逐点即时告警”的差别。无需先复现整套 LSTM，避免旧 TensorFlow 兼容工作挤占 P0。

### 2.6 River / ADWIN：低成本漂移监视，属于 P1

**已核验事实。** [online-ml/river](https://github.com/online-ml/river)为 BSD-3-Clause；[JMLR 2021 River 论文](https://www.jmlr.org/papers/v22/20-1380.html)直接链接仓库，预印本 [arXiv:2012.04740](https://arxiv.org/abs/2012.04740)。[当前 README](https://github.com/online-ml/river/blob/main/README.md)说明在线 `learn_one`/`predict_one` 等接口、顺序预测后更新的示例和 Windows wheels，当前开发分支要求 Python 3.11+。[ADWIN 文档](https://riverml.xyz/latest/api/drift/ADWIN/)说明 `update(x)`接收标量、比较自适应窗口内子窗口的均值并提供 `drift_detected`；River 实现采用 ADWIN2。原方法论文为 Albert Bifet、Ricard Gavaldà，SDM 2007，[作者稿](https://www.cs.upc.edu/~gavalda/papers/adwin06.pdf)，正式 DOI [10.1137/1.9781611972771.42](https://doi.org/10.1137/1.9781611972771.42)，由 [作者所在机构研究记录](https://researchportal.ip-paris.fr/en/publications/learning-from-time-changing-data-with-adaptive-windowing/)核对。

**本课题建议。** P1 先做漂移监视，而非直接全自动在线重训练：在训练/校准期定义一个标量，如经固定规则缩放的 AE/IF 分数或选定特征的时间残差，再在时间测试流监视变化。若输入是预测错误率，需要真实标签的可用时刻与延迟；如果输入无标签分数，只能声称观测到分数分布/均值变化，不能据此确认攻击或真实概念漂移。日夜正常周期也可能触发，适合检验“周期去除后漂移告警是否更稳定”的候选问题。

**难度与资源评估。** 接口接入低至中，研究协议中；CPU 逐样本处理值得试验。River 不是网络 NIDS 成品，UGR’16 时间重放、标签延迟及更新策略仍需独立实现。工具论文与 ADWIN 原论文都应引用，不能只引用库名。

**本课题建议。** 用于开题中“网络环境变化/漂移适应已有研究”的直接相关工作，并从其方法与当前 P0 的差别出发论证范围：本题先问时间上下文是否改善分数/误报，ReCDA 处理表示与分类器适应且需要相应标签设置。若进入 P1，先核实数据预处理、标签映射、recent/historical 分组与时间顺序、完整依赖和模型文件目录；不要仅照两条命令就将它纳入必做实验。按未知攻击类别分组不自动等同自然时间漂移，移植到 UGR’16 必须重新定义评价协议。

## 3. 可以形成的最小实验结构（建议，未运行）

1. **先固定数据单位。** 若采用 FeatureData，每行通常是分钟聚合观察，应以窗口级异常标签评价；若选原始流或包级数据，重新定义检测单位。CSV/MAT 对齐、攻击计数规则与连续性先过 Data Gate。
2. **RQ1 独立做时间规律检验。** 在训练区间观察日内与工作日/周末模式，在留出时间检验稳定性；将无稳定周期的特征或期间单独报告。不得因 UGR’16 题名含 cyclostationarity 就预设可用。
3. **RQ2 建立少而明确的对照。** 统计规则、IF、轻量 AE 共用训练/校准/测试区间、预处理和评价单位。模型在训练批次内的 shuffle 与跨时间区间随机拆分是两回事；后者不能替代当前时间协议。
4. **RQ3/RQ4 每次只改变一项。** 对同一 AI 分数分别比较固定阈值、时间上下文/残差变体与简单融合；保存原始分数和阈值。时间分支、AI 分支、组合与融合消融避免同时换数据版本和参数预算。
5. **指标兼顾漏检与误报。** Precision/Recall/F1、FPR、PR-AUC及分时段/分攻击分析；延迟仅在时间戳和标签边界能支持时计算。给出耗时、内存与显存实测，不能使用仓库/论文数字作为本机结果。

这一结构可作为 P0 的候选实验设计，不强依赖完整在线重训练、付费 API、大模型或包捕获系统；能否完成仍需数据与最小试验证据。时间增强若无收益，应保留负结果和边界，而非追加复杂模型来掩盖问题。
